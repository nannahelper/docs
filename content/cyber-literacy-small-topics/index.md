# 小专题

这里不按课程顺序讲理论，只解决一个个刚开始用电脑时会遇到的小问题。你可以直接点进当前遇到的那一项，不需要从头学习，也不需要先认识专业名词。

每个专题都先用一个简单比喻解释，再给出一条安全、可复现的操作路径。遇到需要删除文件、修改系统设置、登录账号或安装软件的步骤，先读完“不要做什么”，不确定就停下来。

## 使用方法

1. 只打开与你当前问题最接近的专题。
2. 先读开头的简单解释和“先给结论”，再执行步骤。
3. 每完成一步就看预期结果；不一致时不要跳过失败处理。
4. 解决后记下你使用的系统、软件版本和最终位置，方便下次复查。

小专题不会替代完整课程：如果你反复遇到网页、账号、搜索或开发环境问题，再回到[赛博扫盲分类总览](../categories/cyber-literacy.md)选择对应课程。
