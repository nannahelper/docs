# 浏览器该怎么选

## 先理解：浏览器是看网页的窗口

> 🪟 **浏览器像一扇窗，不是互联网本身。** 窗户品牌不同，看到的街道仍然是互联网。先选一扇稳定、更新及时、你会使用的窗，不必追逐“最强”。

## 先按使用场景选

| 你的情况 | 可以优先考虑 | 选择理由 |
|:---|:---|:---|
| Windows 新电脑，只想稳定上网 | Edge | 通常已安装，系统兼容性好 |
| 已经使用 Google 账号和 Chrome 扩展 | Chrome | 账号同步和扩展生态方便 |
| 更在意开源、隐私和跨平台体验 | Firefox | 设置和隐私控制较丰富 |
| 学校或单位要求指定浏览器 | 按要求使用 | 某些系统只验证特定环境 |

这些不是排名。浏览器的实际体验还会受到版本、扩展、设备性能和网站兼容性的影响。

## 第一次设置只做三件事

1. 从浏览器官网或系统应用商店安装，不从不明下载站获取“破解版”。
2. 打开设置，确认自动更新处于开启状态；更新前先关闭重要页面或保存表单。
3. 需要同步书签时，先看清同步的内容和账号，不要在公共电脑上登录个人浏览器账号。

“默认浏览器”和“默认搜索引擎”不是一回事：前者决定链接用哪个程序打开，后者决定地址栏搜索交给谁。可以分别设置，不必因为换了搜索引擎就更换浏览器。

## 出现问题怎么排查

先用无痕窗口或暂时禁用最近安装的扩展测试；如果只有一个网站打不开，再尝试另一个浏览器比较。不要为了修复一个网页，随意关闭安全警告、安装陌生扩展或导入来历不明的证书。

## ✅ 完成检查

说清楚自己当前使用的浏览器、版本、是否登录同步账号、安装了哪些扩展，以及“默认浏览器”和“搜索引擎”分别是什么。
