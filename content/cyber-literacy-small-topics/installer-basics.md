# 安装包到底是什么

## ELI5：安装包是搬家车

<div class="eli5-panel"><div class="eli5-icon">📦</div><div><span class="eyebrow">ELI5</span><h2>软件不是下载完就一定能用</h2><p>安装包像搬家车，把程序、图标和运行所需的文件放到合适的位置。搬家前要确认车是谁的，搬家时要看它往哪里搬。</p></div></div>

## 先分清三种文件

| 文件形式 | 常见特点 | 第一次怎么处理 |
|:---|:---|:---|
| `.exe` / `.msi` | Windows 安装程序，可能会写入系统 | 只从官方来源下载，运行前确认名称和发布者 |
| `.dmg` / `.pkg` | macOS 常见安装形式 | 从官方页面下载，安装后按说明退出或移除安装盘 |
| `.zip` / `.tar.gz` | 压缩包，可能是源代码或便携程序 | 先解压查看 README 和文件类型，不要见到 `.exe` 就运行 |

扩展名只是线索，不是安全证明。一个文件即使叫“安装包”，也可能来自仿冒网站或被重新打包。

## 安装前检查清单

1. 看地址栏域名，优先从软件官网、官方仓库的 Release 页面或系统包管理器进入。
2. 看系统和架构是否匹配，例如 Windows、macOS、Linux，以及 x64、ARM64。
3. 看文件名、发布者、版本和更新时间；与官方页面写的内容对照。
4. 安装时选择自定义选项，阅读是否要安装浏览器、开机启动、额外工具或修改默认设置。
5. 安装结束后，从开始菜单或官方说明打开软件，再检查版本号；不要连续重复运行安装器。

## 这些情况先停下来

- 下载页要求关闭杀毒软件、绕过系统警告或粘贴命令到终端。
- 安装器要求读取与软件无关的个人文件、浏览器密码或通讯录。
- 文件来自网盘、聊天群或“破解资源”，找不到对应的官方发布页。
- 你不知道某个勾选项会安装什么，或需要管理员权限却无法解释原因。

不要下载或传播盗版、破解和绕过授权的安装包。遇到无法确认的文件，保留下载地址、文件名和提示信息，先咨询老师、管理员或软件官方支持。

## ✅ 完成检查

对一个正规软件写出“来源、系统版本、文件类型、安装位置、版本号”五项记录。能解释每一项，就不再只是机械地双击下一步。
