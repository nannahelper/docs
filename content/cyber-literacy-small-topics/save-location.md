# 文件应该保存在哪里

## ELI5：保存地址就是房间号

<div class="eli5-panel"><div class="eli5-icon">📍</div><div><span class="eyebrow">ELI5</span><h2>文件也需要一个“住址”</h2><p>“我保存了”只说明文件被放进了某个房间；保存地址告诉你它具体住在哪一层、哪一个抽屉。</p></div></div>

## 先认识四个常见位置

| 位置 | 适合放什么 | 需要注意 |
|:---|:---|:---|
| 下载 | 刚从网页拿到、还没整理的文件 | 很容易越积越多，重要文件要再归档 |
| 文档 | 课程笔记、报告和个人资料 | 建议按课程或学期建子文件夹 |
| 桌面 | 正在处理的少量文件和快捷方式 | 不适合作为长期仓库 |
| 项目文件夹 | 一项代码或作业的全部文件 | 不要随意移动其中的子文件和配置 |

## 建一个不会迷路的结构

在“文档”中建立一个课程文件夹，例如：

```text
文档/
└─ 大一课程/
   ├─ 计算机基础/
   ├─ 数学/
   └─ 待读资料/
```

文件名也要说明内容和日期，例如 `计算机基础-第一次作业-2026-09-01.docx`。不要只叫 `新建文档`、`最终版` 或 `最终版2`。

## 下载后找不到文件怎么办

1. 回到浏览器的下载记录，查看文件名和“在文件夹中显示”入口。
2. 如果浏览器没有这个入口，在文件管理器里搜索完整文件名。
3. 找到后先复制到课程文件夹，再决定是否删除下载目录中的重复文件。
4. 如果文件来自陌生网站，先不要打开；确认来源和类型后再处理。

## 不要做什么

- 不要把所有资料长期堆在桌面或下载文件夹。
- 不要在不知道用途时移动项目里的隐藏文件、配置文件或依赖目录。
- 不要用“搜索到一个同名文件”证明它就是刚下载的文件，先看路径、大小和修改时间。

## ✅ 完成检查

随便选一个课程文件，写出它的完整路径，并让同学只看路径就能判断它属于哪门课、什么内容、什么时候生成。
