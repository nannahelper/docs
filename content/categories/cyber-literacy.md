# 赛博扫盲

把电脑从“能打开”变成“能独立学习、判断信息、保护账号和解决问题”的基础训练区。

<div class="section-lead"><span class="eyebrow">CYBER LITERACY</span><h2>先学会在数字世界里独立生活</h2><p>从电脑地图、文件管理、网络和账号安全开始，再进入命令行、开发环境与 AI Agent。</p></div>

## 这类教程解决什么问题

- 能理解电脑、操作系统、程序、文件和网络分别负责什么。
- 能整理资料、做独立备份、观察网页请求，并在问题出现时留下证据。
- 能保护邮箱、代码仓库、云盘和 API Key，再进入命令行、开发环境与 Agent。

## 推荐学习顺序

先建立数字生活底座，再进入开发工具。每门课都可以单独学习，但顺序能减少术语和故障排查上的跳跃。
