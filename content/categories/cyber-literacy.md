# 赛博扫盲

这里面向第一次独立使用电脑、互联网和数字工具的学生。目标不是让你背下很多缩写，而是让你能看懂正在发生什么、完成一次安全操作，并在出错时知道如何停下和求助。

<div class="section-lead"><span class="eyebrow">CYBER LITERACY</span><h2>先把数字生活用明白，再进入开发工具</h2><p>先学浏览器、账号和信息判断；确认自己需要写代码后，再进入终端、工具链和 Agent。</p></div>

## 先分清两层内容

赛博扫盲不是一条必须从头学到尾的长课程。前三门是数字生活底座，适合所有大学新生；后两门是开发扩展，只有准备写代码或使用 AI 编程工具时才需要学习。

| 层级 | 先回答的问题 | 包含课程 | 适合什么时候学 |
|:---|:---|:---|:---|
| 数字生活底座 | 网页、账号和资料怎样安全使用？ | 互联网与浏览器、账号安全与隐私、搜索与信息判断 | 第一次独立处理学习资料和账号时 |
| 开发工具扩展 | 代码怎样在我的电脑上运行？ | 命令行开发环境配置 | 确定要学编程后 |
| AI 协作扩展 | 怎样让 Agent 帮忙又不越权？ | Agent 工具入门 | 已经会终端、Git，并理解 API Key 后 |

每门课都从一个可完成的小任务开始。遇到陌生词，先看本章的解释和示例，不需要提前搜索一整套专业课程。

    每章都按“准备 → 操作 → 看结果 → 处理失败 → 复盘”完成。第一次练习使用公开页面、空目录和占位符；涉及真实账号、支付、密钥、删除文件或外部发布时，先停下来确认。
