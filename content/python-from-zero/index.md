# Python 新手指南

这是一门以命令行记账本为主线的 Python 入门课：先让代码跑起来，再把问题拆成流程、数据和函数。

| 项目 | 内容 |
|---|---|
| 适合人群 | 没有系统编程经验，或想为 AI、数据、自动化打基础的学习者 |
| 预计时长 | 8–10 小时（包含练习） |
| 适用版本 | Python 3.11+ |
| 维护状态 | 维护中 |
| 最后更新 | 2026-08-13 |
| 反馈入口 | [GitHub Issues](https://github.com/nannahelper/docs/issues) |

## 🎯 学习目标

- 能在终端和编辑器中运行 Python 程序
- 能使用条件、循环和函数表达解决问题的步骤
- 能用列表、字典和文件处理真实数据
- 能读懂常见异常，并把程序拆成可维护的小模块
- 完成一个可以新增、查询和统计收支的命令行记账本

## 📋 前置要求

- 会使用文件管理器和终端打开目录。
- 能阅读简单的英文命令和错误提示。
- 不要求提前学习其他编程语言。

## 📚 推荐教材

- [A Concise Introduction to Programming in Python](https://lilybre.lilystudio.space/book/29) —— 适合建立语法和编程基础
- [Automate the Boring Stuff with Python](https://lilybre.lilystudio.space/book/34) —— 适合把 Python 用到日常自动化

## 🚀 快速开始

先安装 Python 3.11 或更新版本，再按章节顺序学习。每章都要先运行示例，完成验证步骤后再做练习。

!!! tip "学习方式"
    每章都先复制代码运行，再改一个小地方观察结果。不要只停留在阅读示例。
