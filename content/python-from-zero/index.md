# Python 新手指南

用一门容易上手、应用面广的语言建立编程思维：先让代码跑起来，再学会把问题拆成数据、流程和函数。

| 项目 | 内容 |
|---|---|
| 适合人群 | 没有系统编程经验，或想为 AI、数据、自动化打基础的学习者 |
| 预计时长 | 8–10 小时（包含练习） |
| 适用版本 | Python 3.11+ |
| 维护状态 | 维护中 |
| 最后更新 | 2026-08-13 |

## 你会完成什么

- 能在终端和编辑器中运行 Python 程序
- 能使用条件、循环和函数表达解决问题的步骤
- 能用列表、字典和文件处理真实数据
- 能读懂常见异常，并把程序拆成可维护的小模块
- 完成一个可以新增、查询和统计收支的命令行记账本

## 推荐教材

- [A Concise Introduction to Programming in Python](https://lilybre.lilystudio.space/book/29) —— 适合建立语法和编程基础
- [Automate the Boring Stuff with Python](https://lilybre.lilystudio.space/book/34) —— 适合把 Python 用到日常自动化
