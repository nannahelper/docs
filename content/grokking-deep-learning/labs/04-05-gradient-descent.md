# 实验 2：第 4–5 章梯度下降

## 实验目标

把“误差推动参数更新”从一个标量扩展到向量和矩阵，比较逐样本更新与批量更新。

## 实验顺序

1. 一个输入、一个权重：观察一次更新如何改变预测。
2. 一个样本、多个权重：观察一个误差如何影响多个参数。
3. 多个样本、逐样本更新：每处理一个样本就更新一次。
4. 多个样本、批量更新：先汇总误差，再统一更新。

## 关键形状

```text
inputs.shape      == (样本数, 特征数)
weights.shape     == (特征数,)
predictions.shape == (样本数,)
errors.shape      == (样本数,)
```

批量更新中的 `inputs.T @ errors` 会沿样本维度汇总每个特征对应的误差贡献，因此结果形状和 `weights` 一致。
