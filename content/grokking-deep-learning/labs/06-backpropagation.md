# 实验 3：多层网络与反向传播

## 实验目标

逐步增加网络复杂度，观察误差如何从输出层传回隐藏层：

```text
一个输入、两个权重
        ↓
一个输入、两个隐藏节点
        ↓
多个输入特征
        ↓
多个样本同时训练
```

## 先看标量链

```python
h = x * w1
prediction = h * w2
```

`w1` 不直接连接预测，而是通过 `h` 影响预测。反向传播需要把每一段局部影响相乘，得到误差对 `w1` 的总体影响。

## 再看矩阵

当输入是向量时，第一层参数是矩阵。`np.outer` 用来组合输入特征和隐藏层误差，使更新结果和第一层权重保持相同形状。

## 排错顺序

1. 检查预测是否应该是标量或向量。
2. 检查每个梯度是否和对应参数形状一致。
3. 检查更新后是否重新计算了前向传播。
4. 检查 `delta` 的符号和更新公式是否一致。
