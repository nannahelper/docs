# 第 12 章：像莎士比亚一样写作：循环层

第 3–11 章里的网络通常把一条输入看成一个整体：输入进来，经过若干层，输出一个预测。但句子、音频、传感器读数和股票价格都不是“一个大数字”，而是一串有顺序的输入。本章要解决的问题是：网络怎样读到第 $t$ 个输入时，还记得前面发生过什么？

## 本章要解决的问题

如果把每个字符单独交给一个只看当前输入的网络，网络无法区分下面两段开头的后续含义：

```text
今天的天气很
这道题的答案很
```

“很”后面应该预测什么，取决于前面已经读过的上下文。循环层（recurrent layer）的办法是维护一个状态向量，把“到目前为止读到的内容”压缩到状态里，再把状态传给下一个时间步。

本章完成后，你应该能够：

- 解释输入 $x_t$、隐藏状态 $h_t$ 和输出 $y_t$ 的角色。
- 手算三个时间步的状态传递，说明当前输入和历史状态分别贡献了什么。
- 写出一个最小 NumPy 循环层，并标注每个数组的形状。
- 说明为什么序列训练需要截断、批量和教师强制等策略。
- 区分“循环层记住了状态”和“模型真正理解了语言”。

## 1. 把一串输入拆成时间步

把一句话按字符拆开后，可以表示成：

```text
x_1 → x_2 → x_3 → x_4 → …
```

每一步都做两件事：

1. 读取当前输入 $x_t$。
2. 结合上一步留下的状态 $h_{t-1}$，计算新的状态 $h_t$。

最小的线性循环层可以写成：

$$
h_t = x_t W_x + h_{t-1}W_h + b
$$

如果还要根据状态预测下一个字符，则再计算：

$$
y_t = h_t W_y + b_y
$$

这里的关键不是公式长，而是同一组 $W_x$、$W_h$ 和 $W_y$ 在每个时间步重复使用。网络不是为每个位置准备一套完全不同的参数，而是学习一套“如何读取当前输入、如何保留历史”的规则。

### 状态像一张不断更新的草稿纸

可以把 $h_t$ 想成读文章时手边的一张草稿纸。读到新词时，你会擦掉一部分旧内容，补进一部分新内容；草稿纸太小会丢信息，更新规则不合适又可能让旧内容逐渐失真。循环层的参数就是在学习“哪些信息应该留下”。

## 2. 先用标量手算状态传递

先不要急着使用矩阵。令：

```text
W_x = 0.6
W_h = 0.5
b = 0
h_0 = 0
x_1 = 1, x_2 = 2, x_3 = 0
```

按照 $h_t = x_tW_x + h_{t-1}W_h$ 计算：

| 时间步 | 当前输入 | 上一步状态 | 新状态 |
|:---:|---:|---:|---:|
| $t=1$ | 1 | 0 | $1×0.6+0×0.5=0.6$ |
| $t=2$ | 2 | 0.6 | $2×0.6+0.6×0.5=1.5$ |
| $t=3$ | 0 | 1.5 | $0×0.6+1.5×0.5=0.75$ |

第三步的输入是 0，但状态仍然是 0.75。这说明循环层的输出不只由当前输入决定，还带着历史信息。实际网络通常会在状态更新后使用 `tanh` 或其他非线性函数，避免数值无限增大；这里暂时保留线性形式，是为了看清状态从哪里来。

## 3. 从标量升级到向量

实际任务中，一个字符或一个词通常先变成向量。假设：

- 批量大小为 `B`。
- 输入特征数为 `D_in`。
- 隐藏状态宽度为 `D_h`。
- 输出类别数为 `D_out`。

则每个时间步的形状为：

| 变量 | 含义 | 形状 |
|:---|:---|:---|
| `x_t` | 当前批次的输入 | `(B, D_in)` |
| `h_prev` | 上一时间步状态 | `(B, D_h)` |
| `W_x` | 输入到状态的权重 | `(D_in, D_h)` |
| `W_h` | 状态到状态的权重 | `(D_h, D_h)` |
| `b` | 状态偏置 | `(D_h,)` |
| `h_t` | 当前状态 | `(B, D_h)` |
| `W_y` | 状态到输出的权重 | `(D_h, D_out)` |
| `y_t` | 当前输出 logits | `(B, D_out)` |

对应的 NumPy 表达式是：

```python
h_t = np.tanh(x_t @ W_x + h_prev @ W_h + b)
logits_t = h_t @ W_y + b_y
```

三个矩阵乘法的结果形状必须分别是 `(B, D_h)`、`(B, D_h)` 和 `(B, D_out)`。如果出现 `(D_h, B)`，先不要通过转置“碰运气”修复，而要回到变量定义检查“哪一维表示批量、哪一维表示特征”。

## 4. 最小循环层实现

下面的函数只负责前向传播。它不包含训练，是为了让你先看清时间步和状态的关系：

```python
import numpy as np


def recurrent_forward(sequence, W_x, W_h, b):
    """sequence: (T, B, D_in), return states: (T, B, D_h)"""
    steps, batch_size, _ = sequence.shape
    hidden_size = W_h.shape[0]
    state = np.zeros((batch_size, hidden_size))
    states = []

    for t in range(steps):
        state = np.tanh(sequence[t] @ W_x + state @ W_h + b)
        states.append(state.copy())

    return np.stack(states)
```

这里采用 `(T, B, D_in)` 的约定：第一维是时间步，第二维是批量，第三维是特征。`state.copy()` 不能省略；如果把同一个可变数组的引用反复放进列表，最后观察到的每个时间步可能都会变成最后一步的状态。

## 5. 从读序列到预测下一个字符

字符级文本生成可以拆成一个监督学习任务：


1. 取一段输入字符，例如 `深度学`。
2. 把每个字符编码成 one-hot 向量或词向量。
3. 让循环层按顺序读取字符。
4. 在每个时间步预测下一个字符，例如目标是 `度学习`。
5. 对每个位置计算交叉熵，再沿时间步求和或求平均。

训练时常用教师强制（teacher forcing）：第 $t+1$ 步的输入使用真实字符，而不是模型上一步猜出的字符。这样训练信号稳定、实现简单；但推理时没有真实答案，模型必须使用自己的预测，因此仍然需要单独测试连续生成效果。

预测时不要直接取最大概率就结束，可以：

- 使用 `argmax` 观察最确定的结果。
- 按概率采样，观察不同温度对多样性和稳定性的影响。
- 限制生成长度，并在遇到结束符时停止。

## 7. 常见错误

- **把 RNN 当成“自动记住一切”的黑盒**：状态是有限维向量，信息会丢失，长序列仍然困难。
- **忘记重置状态**：处理互不相关的句子时沿用上一句的状态，会产生跨样本污染。
- **训练和推理输入不一致**：训练用真实字符，推理却必须用自己的输出，二者的差异要通过生成测试暴露出来。
- **混淆时间步和批量维**：先约定 `(T, B, D)` 或 `(B, T, D)`，再让所有函数遵守同一约定。
- **把概率当作 logits**：交叉熵实现可能需要未归一化 logits，不要在函数之间重复 Softmax。
