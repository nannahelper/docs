# 第 1 章：深度学习简介：为什么应该学习深度学习

## 本章要解决的问题

这一章不急着写复杂网络，先回答一个更基础的问题：深度学习到底在“学习”什么？

读完本章，你应该能用自己的话解释：

- 模型接收什么输入，产生什么预测。
- 参数为什么需要从数据中学习。
- 损失如何告诉模型“这次哪里不对”。
- 训练为什么是很多次小更新，而不是一次得到答案。

## 先建立一个生活中的模型

假设你想根据房间面积预测房价。最开始可以写一条非常粗糙的规则：

```text
预测房价 = 房间面积 × 每平方米价格
```

这里的“每平方米价格”就是一个需要学习的参数。如果预测结果偏低，模型会尝试把这个参数调大；如果预测结果偏高，模型会尝试把它调小。

深度学习只是把这个想法扩展到更多输入、更多参数和更多层。最重要的主线始终没有变：

```text
输入 → 参数 → 预测 → 和目标比较 → 得到损失 → 更新参数
```

## 深度学习和传统编程的区别

传统编程通常是人先写出规则：

```text
输入 + 人写的规则 → 输出
```

机器学习则把规则的一部分交给训练过程寻找：

```text
输入 + 目标 + 可调整的参数 → 训练出规则
```

这不表示机器“自己理解了一切”。它只是在给定数据、模型结构和损失函数的前提下，寻找一组能让损失变小的参数。

## 五个必须分清的词

| 词 | 在学习闭环中的作用 |
|:---|:---|
| 输入 | 模型拿来计算的特征，例如面积、像素或词编号 |
| 参数 | 模型会通过训练改变的数字，例如权重 |
| 预测 | 当前参数对输入做计算得到的结果 |
| 目标 | 我们希望模型输出的答案 |
| 损失 | 用一个数字描述预测和目标有多不一样 |

“模型很复杂”不等于“模型一定学得好”。如果输入、目标或损失设计得不合理，增加层数只会让问题更难排查。

## 一个最小例子

我们先只使用一个输入 `x` 和一个权重 `w`：

```text
x = 2
w = 0.5
prediction = x × w = 1
target = 2
```

模型当前预测为 1，但目标是 2，所以它需要调整 `w`。这一章暂时不要求你计算调整量，只要先看清楚：预测是由当前参数产生的，误差是下一步更新的依据。

## 动手任务

请用纸笔写一个你熟悉的机器学习问题，例如判断邮件是否是垃圾邮件、识别图片中的数字或预测明天的温度，并填出：

1. 输入是什么？
2. 目标是什么？
3. 哪些数字可能成为参数？
4. 预测错误时，损失应该反映什么？

## 常见误解

- **误解：** 深度学习就是把很多层堆起来。**纠正：** 层只是计算结构，真正的学习来自损失和参数更新。
- **误解：** 损失越小，模型就一定越接近现实。**纠正：** 损失只反映你选择的目标和数据，泛化能力还要用没有参与更新的数据检查。
- **误解：** 代码运行没有报错，就说明模型正确。**纠正：** 还需要检查形状、数值、误差趋势和自己的解释。
