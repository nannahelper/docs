# 第 5 章：一次学习多个权重：泛化梯度下降

## 本章要解决的问题

一个输入、一个权重的例子能帮助我们理解方向，但真实样本通常有多个特征。本章把一个权重扩展为一组权重，再把一个样本扩展为多个样本。

## 一个样本、多个权重

输入和权重都是长度为 3 的向量：

```python
inputs = np.array([2., 1., -1.])
weights = np.array([0.5, 0.2, 0.1])
prediction = inputs @ weights
```

一个误差会同时影响三个权重。因为每个权重对应一个输入特征，梯度也应该是形状 `(3,)` 的向量，而不是一个标量。

对平方误差来说，向量形式可以理解为：

```text
weight_gradient = error × inputs × 常数因子
```

输入为负数时，该特征对应的梯度方向也会反过来，这就是不能只凭“预测偏低”判断所有权重都应该增大的原因。

## 多个样本的形状

把样本按行堆成矩阵：

```text
inputs.shape      == (样本数, 特征数)
weights.shape     == (特征数,)
targets.shape     == (样本数,)
predictions       == inputs @ weights
predictions.shape == (样本数,)
```

权重只描述特征如何影响预测，不为每个样本单独保存一套权重。因此 `weights.shape` 不包含样本数。

## 逐样本更新和批量更新

逐样本更新的流程是：

```text
取一个样本 → 预测 → 算误差 → 更新权重 → 处理下一个样本
```

批量更新则是：

```text
一次预测所有样本 → 得到所有误差 → 汇总梯度 → 统一更新一次
```

批量计算中：

```python
predictions = inputs @ weights
errors = predictions - targets
weight_gradient = inputs.T @ errors
```

`inputs.T` 的形状是 `(特征数, 样本数)`，`errors` 的形状是 `(样本数,)`，相乘后样本维度被汇总，结果回到 `(特征数,)`，正好可以更新 `weights`。

## 为什么通常要取平均

如果只把样本数量扩大十倍，梯度总和也可能扩大十倍，导致更新步突然变大。用样本数取平均，可以让学习率的含义更稳定：它不应该仅仅因为数据多了就自动变大。

## 一个样本不等于一个规律

如果有 2 个样本，却要估计 3 个未知权重，数学上可能存在多组都能拟合这两个样本的参数。误差接近零只能说明当前样本被拟合，不能证明模型找到了唯一或可泛化的规律。

## 常见错误

- 把每个样本都分配一组权重，混淆样本维度和特征维度。
- 使用 `inputs @ errors`，没有先转置来汇总每个特征的贡献。
- 逐样本更新时忘记每次使用最新权重。
- 批量更新时重复累加旧梯度。
