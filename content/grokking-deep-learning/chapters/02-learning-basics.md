# 第 2 章：基本概念：机器如何学习

## 把“学习”改写成一个可计算的问题

机器不会像人一样突然“理解”一个概念。它先用当前参数做预测，再把预测和目标比较，最后根据差异调整参数：

```text
输入 → 当前参数 → 预测
                 ↓
              和目标比较
                 ↓
              计算损失
                 ↓
              更新参数
```

后面的每一章都在重复这个循环，变化的只是参数数量、数据形状和更新方法。

## 从一个数字开始

设输入 `x = 2`、权重 `w = 0.5`、目标 `target = 2`：

```text
prediction = x × w = 1
error = prediction - target = -1
loss = error² = 1
```

如果使用平方误差，关于权重的梯度为：

```text
d_loss/d_w = 2 × (prediction - target) × x
           = 2 × (-1) × 2
           = -4
```

学习率取 `0.1` 时：

```text
w_new = w - learning_rate × gradient
      = 0.5 - 0.1 × (-4)
      = 0.9
```

更新后预测值是 `2 × 0.9 = 1.8`，比原来的 1 更接近目标 2。这个例子不是为了让你立刻熟练求导，而是让你看到一次学习步骤的完整因果链。

## 三个容易混淆的词

- **误差**：预测和目标的差，可能有正负。
- **损失**：把误差整理成可比较的指标，常常希望它非负。
- **梯度**：参数改变一点时，损失会朝哪个方向变化、变化有多快。

学习率不是越大越好。步子太大可能跨过低损失区域，步子太小则会让更新非常缓慢。

## 训练数据和泛化

训练数据用于计算反馈，但模型真正有价值的地方是面对没有见过的数据仍然表现合理。于是要区分：

```text
训练集：用于更新参数
验证集：用于观察模型是否泛化
测试集：最后一次客观检查
```

在本书前几章中，我们会先用很小的数据把算法机制讲清楚；到正则化章节，再系统讨论训练误差和验证误差为什么会分离。

## 先想再算

如果当前预测比目标小：

1. 误差 `prediction - target` 的符号是什么？
2. 权重一定要增大吗？如果输入是负数，还能直接这样判断吗？
3. 如果学习率翻十倍，更新可能出现什么现象？

先写下猜测，再用上一节的数字重新计算。预测和实际不一致时，不要马上修改代码，先定位是符号、公式还是学习率的问题。

## 本章验收

用一个具体数字完整写出一次“预测 → 损失 → 梯度 → 参数更新”，并解释为什么更新后的损失应该变小。若没有变小，列出两个可能原因。
