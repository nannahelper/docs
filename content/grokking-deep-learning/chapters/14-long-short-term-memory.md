# 第 14 章：学习像莎士比亚一样写作：长短期记忆网络

第 12 章的循环层可以把历史压缩到一个隐藏状态里，但序列很长时，早期信息可能在反复更新中逐渐消失。比如生成一句话时，模型读到句尾可能仍然需要知道句首的主语、语气或括号是否已经打开。

长短期记忆网络（Long Short-Term Memory，LSTM）没有把所有历史都塞进同一个无区分的状态，而是增加一条更适合长期传递的记忆通道，并用门控制信息的保留、写入和输出。

## 本章要解决的问题

本章不是要求你背下 LSTM 的四个公式，而是要回答：

- 为什么普通 RNN 的状态在长序列中容易丢失？
- LSTM 的“门”分别在控制什么？
- 记忆状态 `c_t` 和隐藏状态 `h_t` 有什么区别？
- 什么时候 LSTM 的复杂度是值得的，什么时候简单 RNN 或 Transformer 更合适？

本章完成后，你应该能够：

- 画出一个 LSTM 时间步的数据流。
- 解释遗忘门、输入门、候选记忆和输出门的作用。
- 写出单个时间步的 LSTM 公式并标注形状。
- 用一个小例子检查门值位于合理范围。
- 设计一个序列任务，说明输入、目标和状态重置方式。

## 1. 普通 RNN 为什么会忘记

普通 RNN 反复使用类似下面的更新：

$$
h_t=\tanh(x_tW_x+h_{t-1}W_h+b)
$$

反向传播穿过很多时间步时，梯度会反复乘上权重矩阵和激活函数的导数。如果这些乘积的数值大多小于 1，梯度会越来越小；如果大于 1，则可能越来越大。这就是梯度消失和梯度爆炸的直观来源。

LSTM 的设计目标不是保证任何序列都能完美记忆，而是提供一条更直接的记忆通道，让模型可以学会“保留多久、什么时候覆盖、什么时候读出”。

## 2. 把 LSTM 想成带阀门的记忆本

每个时间步有两份状态：

- `c_t`：细胞状态，像一条贯穿序列的记忆带。
- `h_t`：隐藏状态，像当前时刻对外公开的工作摘要。

三个门使用 Sigmoid，输出在 0 到 1 之间，可以理解为“允许通过多少”：

- 遗忘门 `f_t`：旧记忆保留多少。
- 输入门 `i_t`：新信息写入多少。
- 输出门 `o_t`：当前记忆暴露多少。

另外还有一个候选记忆 `g_t`，表示当前输入建议写入的内容。门不是人工设定的开关，而是由输入和上一时刻的隐藏状态计算出来、通过训练学会的连续数值。

## 3. 单个时间步的公式

先把当前输入和上一隐藏状态拼接或分别线性变换。常见写法是：

$$
f_t=\sigma([h_{t-1},x_t]W_f+b_f)
$$

$$
i_t=\sigma([h_{t-1},x_t]W_i+b_i)
$$

$$
g_t=\tanh([h_{t-1},x_t]W_g+b_g)
$$

$$
o_t=\sigma([h_{t-1},x_t]W_o+b_o)
$$

然后更新两份状态：

$$
c_t=f_t\odot c_{t-1}+i_t\odot g_t
$$

$$
h_t=o_t\odot\tanh(c_t)
$$

其中 $odot$ 是逐元素乘法。遗忘门负责旧内容，输入门负责新内容，两者相加形成新的细胞状态；输出门再决定这个记忆有多少用于当前输出。

## 4. 形状检查

假设批量大小为 `B`，输入维度为 `D_in`，隐藏维度为 `D_h`：

| 变量 | 形状 | 说明 |
|:---|:---|:---|
| `x_t` | `(B, D_in)` | 当前时间步输入 |
| `h_prev` | `(B, D_h)` | 上一隐藏状态 |
| `c_prev` | `(B, D_h)` | 上一细胞状态 |
| `[h_prev, x_t]` | `(B, D_h + D_in)` | 拼接后的输入 |
| `f, i, g, o` | `(B, D_h)` | 四个门/候选记忆 |
| `c_t` | `(B, D_h)` | 新细胞状态 |
| `h_t` | `(B, D_h)` | 新隐藏状态 |

如果一次性计算四个门，可以把权重合并为一个矩阵：

```python
combined = np.concatenate([x_t, h_prev], axis=1)
gates = combined @ W + b  # (B, 4 * D_h)
forget, input_gate, candidate, output = np.split(gates, 4, axis=1)
```

合并计算只是工程优化，不能改变四个门各自的非线性：三个门用 Sigmoid，候选记忆通常用 `tanh`。

## 5. 最小 NumPy 单步实现

```python
def sigmoid(x):
    return 1 / (1 + np.exp(-x))


def lstm_step(x_t, h_prev, c_prev, W, b, hidden_size):
    combined = np.concatenate([x_t, h_prev], axis=1)
    gates = combined @ W + b
    f_raw, i_raw, g_raw, o_raw = np.split(gates, 4, axis=1)

    f_t = sigmoid(f_raw)
    i_t = sigmoid(i_raw)
    g_t = np.tanh(g_raw)
    o_t = sigmoid(o_raw)

    c_t = f_t * c_prev + i_t * g_t
    h_t = o_t * np.tanh(c_t)
    return h_t, c_t, (f_t, i_t, g_t, o_t)
```

运行前先打印：

```python
print(x_t.shape, h_prev.shape, c_prev.shape)
print(h_t.shape, c_t.shape)
print([gate.min() for gate in gates_tuple])
```

合理的检查结果是：三个 Sigmoid 门的值在 `[0, 1]` 内，候选记忆在 `[-1, 1]` 内，`h_t` 与 `c_t` 都是 `(B, D_h)`。如果门值全部接近 0 或 1，不要立即认为实现错误，也要检查初始化、输入尺度和偏置。

## 6. LSTM 与文本生成

在字符生成任务中，流程可以写成：

```text
字符/词向量 → LSTM 时间步 → 输出 logits → Softmax/交叉熵 → 下一个字符
```

训练时，完整句子被切成固定长度的窗口。窗口之间是否携带状态，需要明确设计：

- 独立窗口：每个窗口开始时把 `h`、`c` 清零，边界清楚但上下文较短。
- 连续窗口：把上一个窗口的状态传给下一个窗口，但要在反向传播时截断计算图，避免显存和计算无限增长。

这就是截断反向传播（truncated backpropagation through time）的基本动机：前向状态可以延续，梯度追溯范围却限制在有限窗口内。

## 7. 动手任务

### 任务 A：观察门如何控制记忆

固定 `x_t` 和权重，只手动改变三个门：

- 令 `f_t=1, i_t=0`，观察 `c_t` 与 `c_prev` 的关系。
- 令 `f_t=0, i_t=1`，观察旧记忆是否被新候选覆盖。
- 令 `o_t=0`，观察 `c_t` 仍然存在但 `h_t` 不再暴露它。

这不是训练，而是用极端值验证公式的语义。

### 任务 B：比较 RNN 与 LSTM

构造一个“开头的标记决定结尾分类”的序列任务，分别使用普通 RNN 和 LSTM。记录序列长度增加后训练损失和验证表现的变化。你不需要追求最佳模型，重点是解释哪一种状态更容易保留早期信号。

## 8. 常见错误

- **把 `c_t` 和 `h_t` 当成同一个状态**：细胞状态负责长期通道，隐藏状态是当前输出摘要。
- **忘记 Sigmoid 的范围**：门值不是任意实数，若门没有经过 Sigmoid，更新语义会改变。
- **门的切分顺序前后不一致**：定义为 `forget, input, candidate, output` 后，所有代码都要保持同一顺序。
- **跨无关样本传递状态**：不同句子或不同用户的序列通常要重置状态。
- **认为 LSTM 自动解决长文本理解**：它缓解梯度和记忆问题，但仍受容量、数据、训练目标和上下文长度限制。
