# 第 4 章：神经网络学习简介：梯度下降

## 一个权重如何学会靠近目标

把网络先简化成一个输入、一个权重和一个目标：

```text
prediction = input × weight
error      = prediction - target
```

如果预测偏小，权重通常需要向增大的方向调整；如果预测偏大，权重通常需要向减小的方向调整。但真正的更新方向还取决于输入的符号和误差对参数的影响。

## 更新不是猜，而是利用斜率

平方误差常写成：

$$
E = (prediction - target)^2
$$

梯度描述了“权重动一点，误差会怎样变化”。梯度下降的基本形式是：

```text
weight = weight - learning_rate × gradient
```

减号表示朝着误差下降的方向移动，学习率控制每次移动的步幅。

## 动手实验
