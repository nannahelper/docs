# 第 4 章：神经网络学习简介：梯度下降

## 本章要解决的问题

第 3 章解决了“如何预测”，本章解决“预测错了以后怎样调整权重”。先把网络压缩成一个输入、一个权重和一个目标，所有更新都能手算。

```text
prediction = input × weight
error      = prediction - target
loss       = error²
```

## 梯度告诉我们往哪边走

平方误差为：

$$
E=(\hat{y}-y)^2
$$

对权重求导时要沿着计算路径使用链式法则：

$$
\frac{\partial E}{\partial w}=2(\hat{y}-y)x
$$

梯度为负，表示在当前点增大权重会让损失下降；梯度为正，表示应该减小权重。于是更新公式是：

```text
weight = weight - learning_rate × gradient
```

减号不是装饰，它表示朝着损失下降的方向移动。

## 手算一次更新

取 `x=2`、`weight=0.5`、`target=2`：

```text
prediction = 1
error = -1
gradient = 2 × (-1) × 2 = -4
```

学习率为 `0.1` 时：

```text
new_weight = 0.5 - 0.1 × (-4) = 0.9
new_prediction = 2 × 0.9 = 1.8
```

如果这一步让损失变大，不要先怀疑 NumPy，先检查梯度符号、学习率和更新前后是否重新计算了预测。

## 学习率的三个实验

分别尝试很小、合适和很大的学习率，并记录：

| 学习率 | 可能观察到的现象 |
|:---|:---|
| 太小 | 损失下降很慢，很多轮后仍未接近目标 |
| 合适 | 损失整体下降，参数逐步稳定 |
| 太大 | 损失震荡、越过低点，甚至越来越大 |

不要只看最后一轮。把每轮的权重、预测和损失打印或记录下来，才能看出更新轨迹。

## 一次训练步的固定顺序

```text
1. 用当前参数前向传播
2. 计算误差和损失
3. 计算梯度
4. 按学习率更新参数
5. 用新参数重新计算下一轮
```

把第 5 步漏掉，或者在计算梯度前就覆盖旧参数，都会让实验结果难以解释。

## 动手实验

1. 先用纸笔完成一个更新。

3. 运行[配套 Notebook](../labs/notebooks/04-05-gradient-descent.ipynb)。
4. 只改变学习率，比较三条损失变化轨迹。

## 常见错误

- 把 `target - prediction` 和 `prediction - target` 混用，却没有同步修改梯度。
- 以为误差为负就一定要增加权重，忽略了输入也可能为负。
- 更新了权重，却继续使用旧预测计算下一轮。
- 只看最终误差，不检查中间轮次是否已经发散。
