# 第 6 章：构建第一个深度神经网络：反向传播简介

## 误差如何传回更早的层

多层网络的预测经过多个中间变量：

```text
输入 → 第一层 → 隐藏层 → 第二层 → 预测 → 误差
```

最后的误差没有直接连接到每一个早期权重。反向传播利用链式法则，把“最终误差对当前变量的影响”沿计算路径逐层传回。

## 先从标量开始

最小的两层网络可以写成：

```python
h = x * w1
prediction = h * w2
```

`w2` 直接影响预测，`w1` 则要先通过隐藏值 `h` 才能影响预测。链式法则正是在描述这条间接路径。

## 再看形状

当隐藏层有多个节点时，标量会变成向量；当输入有多个特征时，第一层参数会变成矩阵。此时常见的形状关系是：

```text
X.shape  == (样本数, 特征数)
W1.shape == (特征数, 隐藏节点数)
H.shape  == (样本数, 隐藏节点数)
W2.shape == (隐藏节点数,)
```

梯度的形状必须和对应参数一致。形状不匹配通常不是“NumPy 太奇怪”，而是你还没有明确每个维度代表什么。
