# 第 6 章：构建第一个深度神经网络：反向传播简介

## 本章要解决的问题

前向传播把输入送到预测端，反向传播则把最终误差沿相反方向传回每个参数。它不是另一种神秘的训练方式，而是把链式法则系统地应用到计算图上。

```text
输入 → 第一层 → 隐藏层 → 第二层 → 预测 → 损失
损失 → 梯度 → 第二层 → 隐藏层 → 第一层 → 输入
```

## 先从标量网络开始

最小的两层网络：

```python
h = x * w1
prediction = h * w2
loss = (prediction - target) ** 2
```

设 `d_loss/d_prediction` 已经算出，链式法则给出：

```text
d_loss/d_w2 = d_loss/d_prediction × h
d_loss/d_h  = d_loss/d_prediction × w2
d_loss/d_w1 = d_loss/d_h × x
```

`w2` 直接影响预测，所以只经过一段路径；`w1` 要先影响 `h`，再影响预测，因此它的梯度要沿两段路径相乘。

## 再看多个隐藏节点

当隐藏层有两个节点时：

```text
x (标量)
  ├─ w1[0] → h[0]
  └─ w1[1] → h[1]
h (2,) @ w2 (2,) → prediction (标量)
```

此时 `w2_delta` 是向量，因为两个隐藏节点都对预测有贡献。对于第一层参数，输入和隐藏层梯度需要组合成矩阵：

```python
w1_delta = np.outer(x, hidden_delta)
```

如果 `x.shape == (3,)`、`hidden_delta.shape == (2,)`，外积结果就是 `(3, 2)`，与 `w1.shape` 一致。

## 多个输入和多个样本

当输入有多个特征、数据有多个样本时：

```text
X       (N, D)
W1      (D, H)
H=X@W1  (N, H)
W2      (H,)
预测    (N,)
```

每个梯度都必须对应它负责更新的参数：

```text
dW1.shape == W1.shape
dW2.shape == W2.shape
dX.shape  == X.shape
```

形状不匹配时，不要马上加 `reshape`。先写出每个维度的含义，确认自己是在修复数学表达，还是只是在掩盖错误。

## 前向缓存为什么重要

反向传播需要知道前向传播经过了哪些中间值。例如计算 `w1` 的梯度时需要 `x`、`w2` 和隐藏层相关的梯度。如果前向阶段没有保存它们，反向阶段就只能猜或重复计算。

更复杂的网络通常把每层的缓存保存成结构化对象，反向传播按相反顺序逐层读取。

## 用数值梯度做检查

手写梯度最容易出现符号或维度错误。可以用一个很小的 `epsilon` 做有限差分：

```text
数值梯度 ≈ [loss(w + epsilon) - loss(w - epsilon)] / (2 × epsilon)
```

它不是训练方法，而是用来检查手写导数是否大致正确。比较时允许有微小浮点误差，但如果方向完全相反，就要优先检查公式和参数更新顺序。

## 常见错误

- 把反向传播理解成“把误差直接复制给每个权重”。
- 忘记链式法则中的中间导数。
- 梯度数组形状和参数形状不一致。
- 更新了参数，却没有用新参数重新进行前向传播。
- 只看最终损失，不检查每一层的中间值。
