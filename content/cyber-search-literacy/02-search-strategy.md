# 第 2 章：搜索策略 — 不要只换一句自然语言

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 15 分钟 |
| 核心概念 | 引号、site、filetype、减号、版本、关键词 |
| 核心比喻 | 换几把钥匙开门 |
| 实践任务 | 为一个技术问题设计三组查询 |

搜索不是一次抽奖，而是不断缩小范围。先用普通关键词了解方向，再加版本、平台、官方站点和错误原文。

## 2.1 常用搜索写法

| 写法 | 作用 | 示例 |
|:---|:---|:---|
| 引号 | 搜精确短语 | `"command not found"` |
| `site:` | 限定网站 | `site:python.org venv` |
| `filetype:` | 限定文件类型 | `filetype:pdf study guide` |
| `-词语` | 排除结果 | `python install -course` |
| 版本号 | 限定适用环境 | `Windows 11 Python PATH` |

## 2.2 三轮搜索法

第一轮只问主题，了解它有哪些术语；第二轮加入官方站点和版本；第三轮加入完整错误原文和你的实际动作。不要因为第一轮结果不理想就认定“网上没有答案”。

## 2.3 识别广告和聚合站

搜索结果顶部可能是广告或转载。查看域名、页面作者、更新时间和是否能链接到官方文档；软件下载优先从官方发布页进入，不从不明下载站点获取安装程序。

## ✅ 验证步骤

针对同一问题写宽泛版、限定官方站点版和加入错误原文版三组查询，比较结果质量；打开至少一个官方结果，确认它真的解决了你的问题。

## ❌ 常见情况

| 现象 | 改进方法 |
|:---|:---|
| 结果被课程广告占满 | 加 `site:`、版本和具体动作 |
| 只找到旧教程 | 搜索当前版本和官方更新日志 |
| 错误原文搜不到 | 只保留最稳定的关键词，去掉临时路径 |
| 搜索结果互相矛盾 | 记录日期和版本，再回到一手来源 |

## 📝 本章总结

- 查询条件越接近你的实际环境，结果越可用。
- 搜索到页面不等于找到证据，必须打开并阅读。

## ✏️ 课后练习

搜索一个软件的官方安装文档、版本说明和卸载说明，分别保存链接并写出三者用途。
