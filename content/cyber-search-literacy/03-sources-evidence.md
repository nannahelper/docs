# 第 3 章：来源与证据 — 谁亲眼见过这件事

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 25 分钟 |
| 核心概念 | 一手来源、二手来源、日期、版本、证据 |
| 核心比喻 | 证人和原始记录 |
| 实践任务 | 给两个来源做可信度标注 |

官方文档、原始论文、项目仓库和原始数据通常更接近事实；博客、视频和帖子适合帮助理解，但要回到一手来源核对。来源可靠不等于结论适用于你的版本。

## ✅ 验证步骤

为两个来源记录作者或机构、发布时间、更新时间、适用版本、原始证据和可能的利益关系。

## ✏️ 课后练习

找一条“某软件最新功能”的说法，核对官方更新日志或文档。
