# 搜索与信息判断：从“搜到”到“确认是真的”

大学学习不只是找到答案，还要知道答案从哪里来、是否适用于当前版本，以及怎样让别人复核你的判断。

## 📖 关于本教程

| 项目 | 内容 |
|:---|:---|
| 适合人群 | 想提高搜索、查资料和使用 AI 可靠性的大学新生 |
| 预计时长 | 约 2 小时（包含核验练习） |
| 适用版本 | 主流搜索引擎、浏览器和 AI 工具；页面功能以当前版本为准 |
| 维护状态 | 维护中 |
| 最后更新 | 2026-08-13 |
| 反馈入口 | [GitHub Issues](https://github.com/nannahelper/docs/issues) |

## 🎯 学习目标

- 能把模糊问题拆成可搜索的关键词和约束条件。
- 能优先找到官方文档、原始论文或一手数据，并记录版本和日期。
- 能识别 AI 生成内容中的未验证结论，完成最小事实核查。

## 📋 前置要求

- 会使用浏览器搜索和复制链接。
- 不要求掌握学术检索工具。

## ✅ 完成标准

针对一个真实问题，产出“问题定义、至少两个来源、关键证据、适用范围和结论”的短笔记。
