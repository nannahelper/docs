# 第 5 章：同步和备份 — 有副本才算有退路

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 65 分钟 |
| 核心概念 | 工作副本、同步、副本、备份、版本 |
| 核心比喻 | 影分身和保险箱 |
| 实践任务 | 建立一份独立备份并检查它 |

本地工作副本是你正在编辑的文件；同步会把变化传播到其他设备；备份是为了在误删、损坏或设备丢失后回到过去。同步很方便，但误删也可能同步发生，所以同步不自动等于备份。

## 5.1 三种位置

| 位置 | 作用 | 风险 |
|:---|:---|:---|
| 电脑本地 | 方便编辑和运行 | 电脑坏了可能一起丢 |
| 云同步目录 | 多设备保持接近一致 | 误删可能同步传播 |
| 独立备份 | 保留可恢复副本 | 需要主动更新和检查 |

重要作业至少要有本地工作副本和另一位置的副本；关键资料还应有不同时间点的版本。

## 5.2 设置云同步时看清楚什么

登录云盘前确认网址和账号，选择一个明确的同步文件夹。打开“在线占位”或类似功能时，确认文件是否真的已下载到本机。不要把桌面、整个硬盘和含密钥的目录一股脑同步到公共账号。

## 5.3 做一次独立备份

1. 新建一个不含隐私的练习文件。
2. 在电脑上保存它，并记下路径和日期。
3. 连接另一块磁盘或打开可信的备份位置。
4. 创建 `backup-YYYY-MM-DD` 文件夹。
5. 复制练习文件进去，不要移动原文件。
6. 关闭原文件，在备份位置打开副本。
7. 记录备份位置、时间和检查结果。

## 5.4 不要备份什么

密码、API Key、验证码、身份证件扫描件和私人聊天记录不应放进公开仓库或共享链接。敏感资料需要可信的加密存储；如果不确定，先咨询学校或服务商的官方说明。

## ✅ 验证步骤

修改本地练习文件的一句话，确认云同步或备份位置不会神秘地把原版本覆盖到你无法恢复；打开独立副本并比较内容，写下两个位置的差异。

## ❌ 常见情况

| 现象 | 处理方法 |
|:---|:---|
| 云盘显示同步完成但本地打不开 | 确认文件是否已下载，检查网络和权限 |
| 删除后所有位置都没了 | 查云盘回收站和历史版本，不要继续操作同名文件 |
| 备份位置空间不足 | 清理旧的大文件版本，但先确认关键版本已保留 |
| 复制过程中断 | 比较文件大小和打开结果，不要把半成品当备份 |

## 📝 本章总结

- 同步强调“保持一致”，备份强调“可以回到过去”。
- 复制比移动更适合第一次做备份。
- 备份必须包含位置、时间和检查记录。
