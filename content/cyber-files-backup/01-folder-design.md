# 第 1 章：文件和文件夹 — 先决定资料住在哪里

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 50 分钟 |
| 核心概念 | 文件、文件夹、当前位置、复制、移动、删除 |
| 核心比喻 | 宿舍楼、房间和储物柜 |
| 实践任务 | 建立本学期学习目录并放入练习文件 |

文件像物品，文件夹像抽屉，当前位置像你此刻站在哪个房间。先建立位置，再保存内容；不要一开始就把资料散落在桌面。

## 1.1 打开文件管理器

Windows 打开“文件资源管理器”，macOS 打开“访达”，Ubuntu 打开“文件”。左侧常见的“桌面、文档、下载、图片”是快捷入口，不一定是全部文件。

观察窗口上方的地址位置。它告诉你当前正在看哪个文件夹。点击上一级按钮后，你会回到外层；双击文件夹名称则会进入内层。

## 1.2 创建目录

1. 进入“文档”或 `Documents`。
2. 右键空白处，选择“新建文件夹”。
3. 输入 `大学学习`，按 `Enter`。
4. 进入它，创建 `2026-秋季学期`。
5. 继续创建 `课程资料`、`作业提交`、`个人项目`、`参考资料` 和 `待整理`。
6. 逐个双击进入，再用上一级按钮返回，确认层级确实建立成功。

```text
大学学习/
└── 2026-秋季学期/
    ├── 课程资料/
    ├── 作业提交/
    ├── 个人项目/
    ├── 参考资料/
    └── 待整理/
```

## 1.3 复制和移动的区别

复制像复印一份，原件仍在原处；移动像把唯一一份物品搬到新房间。第一次整理重要资料时优先复制，确认新副本打开正常后再考虑删除旧副本。

选中一个练习文件，使用复制和粘贴放入“课程资料”；再使用“剪切”和粘贴把另一份练习文件放入“待整理”。回到原来的位置，观察哪一个仍然存在。

## 1.4 删除和回收站

普通删除通常先把文件放进回收站或废纸篓。它仍可能占用空间，也可能被恢复。删除前先确认文件名、位置和内容；不要为了“清爽”清空整个回收站。

## ✅ 验证步骤

关闭文件管理器，再重新打开它；不看桌面图标，依次进入“文档 → 大学学习 → 2026-秋季学期 → 课程资料”，找到练习文件并打开。然后从“待整理”复制一份到“个人项目”，确认两个位置都有副本。

## ❌ 常见情况

| 现象 | 处理方法 |
|:---|:---|
| 找不到“新建文件夹” | 先点击空白处再右键，或使用窗口顶部的新建按钮 |
| 文件拖动后消失 | 先检查目标文件夹和回收站，不要立即再次拖动 |
| 误删了文件 | 立即打开回收站，按文件名确认后恢复 |
| 目录太深找不到 | 返回上一级，先看地址栏，再继续进入 |

## 📝 本章总结

- 文件夹是组织工具，不会自动备份内容。
- 复制会留下两份，移动通常只留下新位置的一份。
- 删除前先确认，第一次整理重要资料优先复制。

## ✏️ 课后练习

为两门课程各创建“资料、作业、参考”三个子文件夹，并把 3 份练习文件分别放入正确位置。完成后重新打开电脑，再从目录进入找到它们。
