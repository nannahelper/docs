# 文件管理与备份：让资料找得到、丢不了

从“下载完就找不到”开始，建立适合大学课程、作业和项目的文件命名、归档、同步与备份习惯。

## 📖 关于本教程

| 项目 | 内容 |
|:---|:---|
| 适合人群 | 文件散落在桌面、下载目录和聊天记录中的大学新生 |
| 预计时长 | 约 2 小时（包含练习） |
| 适用版本 | Windows 11、macOS 14+、Ubuntu 22.04+；云盘界面以当前版本为准 |
| 维护状态 | 维护中 |
| 最后更新 | 2026-08-13 |
| 反馈入口 | [GitHub Issues](https://github.com/nannahelper/docs/issues) |

## 🎯 学习目标

- 能为课程、项目和个人资料设计稳定的目录结构。
- 能用统一规则命名、归档和查找文件。
- 能区分同步、备份和版本控制，完成一次可恢复的备份演练。

## 📋 前置要求

- 会使用文件管理器和浏览器。
- 有一个可用的本地磁盘和一个云盘或移动存储位置。
