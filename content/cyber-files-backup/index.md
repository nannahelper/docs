# 文件管理与备份：让资料找得到、丢不了

从“下载完就找不到”开始，建立适合大学课程、作业和项目的文件习惯。你会实际创建目录、命名文件、识别格式、使用压缩包、区分同步和备份，并亲手做一次恢复演练。

## 📖 关于本教程

| 项目 | 内容 |
|:---|:---|
| 适合人群 | 第一次独立整理课程资料、经常在桌面和下载目录找文件的毕业生 |
| 预计时长 | 约 1.5–2 小时（按一遍阅读、跟做和验证估算） |
| 适用版本 | Windows 11、macOS 14+、Ubuntu 22.04+；云盘界面以当前版本为准 |
| 维护状态 | 维护中 |
| 最后更新 | 2026-08-13 |
| 反馈入口 | [GitHub Issues](https://github.com/nannahelper/docs/issues) |

## 🎯 学习目标

- 能理解文件、文件夹、路径、扩展名和压缩包的区别。
- 能为课程、作业、项目和参考资料设计可长期使用的目录。
- 能按统一规则命名、搜索和归档文件。
- 能区分本地副本、同步副本、备份副本和 Git 版本库。
- 能从独立备份恢复一份文件，并写出恢复记录。

## 📋 前置要求

- 完成[电脑与操作系统](../cyber-computer-basics/index.md)第 1–3 章，或已经会打开文件管理器。
- 有一份不含隐私的练习文件；不要拿身份证、密码或重要作业做第一次演练。

## 🚀 开始前准备

准备一个 `大学学习` 文件夹和 3 份可随时删除的练习文件。第一次不要整理整个硬盘，也不要把所有文件一口气拖来拖去；我们每次只处理一小块。

## ✅ 完成标准

你能在不依赖桌面快捷方式的情况下找到一份资料，知道它的正式位置、备份位置和恢复步骤，并能解释同步和备份为什么不是一回事。
