# 第 4 章：同步与备份 — 有副本才算有退路

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 30 分钟 |
| 核心概念 | 同步、备份、副本、版本 |
| 核心比喻 | 影分身与保险箱 |
| 实践任务 | 建立一份独立备份 |

同步会把变化传播到多个设备，误删也可能一起传播；备份则保留可以回到过去的独立副本。重要作业不能只放在一个聊天窗口或一台电脑里。

## 4.1 最小可行方案

- 工作副本：电脑上的学习目录。
- 同步副本：云盘中的同名目录，方便换设备。
- 独立备份：每周复制到另一块磁盘或另一项服务。

## ✅ 验证步骤

复制一份不敏感的练习文件到备份位置，记录备份日期；再把本地副本改名或移走，从备份位置恢复它。

!!! warning "不要备份秘密"
    API Key、密码和身份证件扫描件不要放进公开仓库或共享链接；敏感资料应使用可信的加密存储。

## ✏️ 课后练习

写下你的三份副本分别在哪里、多久更新一次、丢失电脑后如何拿到它们。
