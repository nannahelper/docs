# 第 2 章：命名与搜索 — 让未来的自己看得懂

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 20 分钟 |
| 核心概念 | 日期、版本、关键词、扩展名 |
| 核心比喻 | 书名和索书号 |
| 实践任务 | 批量整理三份文件 |

推荐格式：`日期_课程_主题_版本`，例如 `2026-09-01_math_homework_v02.pdf`。日期统一使用 `YYYY-MM-DD`，版本统一使用 `v01`、`v02`。

## 2.1 不要这样命名

`最终版.pdf`、`老师发的那个.pptx`、`新建文件夹(3)` 都无法回答“它是什么、何时产生、哪一版”。

## ✅ 验证步骤

把三份下载资料重命名后，用系统搜索分别按课程名和主题关键词查找。搜索结果应能区分不同日期和版本。

## ✏️ 课后练习

写下自己的命名模板，并用它命名一份作业和一份参考资料。
