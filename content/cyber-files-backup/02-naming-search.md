# 第 2 章：命名和搜索 — 让未来的自己看得懂

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 15 分钟 |
| 核心概念 | 文件名、日期、关键词、版本、排序、搜索 |
| 核心比喻 | 书名和索书号 |
| 实践任务 | 整理 5 份文件并用搜索找回 |

文件名是标签，搜索是图书馆目录。好的名字不依赖“我记得它大概在桌面上”，而是让几周后的你也能判断它是什么。

## 2.1 一套简单命名规则

推荐格式：`日期_课程_主题_版本`，例如 `2026-09-01_math_notes_v01.pdf`。日期统一使用 `YYYY-MM-DD`，版本统一使用 `v01`、`v02`。如果是最终提交，可以增加 `submit`，但不要让“最终”成为唯一信息。

## 2.2 重命名一步一步做

1. 在文件管理器中选中练习文件。
2. 右键选择“重命名”，或按系统提供的重命名快捷键。
3. 只修改文件名，不要删除最后的扩展名。
4. 输入 `2026-09-01_intro_notes_v01.txt`。
5. 按 `Enter`，再双击文件，确认仍能打开。
6. 复制一份，改为 `v02`，在内容中增加一行，再保存。

## 2.3 按名称、时间和类型排序

在文件夹空白处右键或点击“排序”，尝试按名称、修改日期和类型排序。排序只改变当前显示顺序，不会改变文件本身。按修改日期能找到刚刚编辑过的作业，按类型能集中看到 PDF 或图片。

## 2.4 用搜索找回文件

1. 记住文件名中的一个独特词，例如 `intro`。
2. 打开文件管理器搜索框，输入这个词。
3. 等待搜索完成，不要看到一个结果就马上打开来路不明的文件。
4. 查看搜索结果的完整路径，确认它确实位于课程目录。
5. 打开文件并检查内容，再决定是否移动。

搜索关键词越具体越好。`作业` 可能找到几百份资料，`2026-09-01_math` 会更容易定位。

## ✅ 验证步骤

把 5 份练习文件改成包含日期、课程、主题和版本的名称；关闭文件夹后，用课程名搜索一次，用文件类型或日期排序一次；每次都打开正确文件并确认路径。

## ❌ 常见情况

| 现象 | 处理方法 |
|:---|:---|
| 重命名后文件打不开 | 检查是否误删了扩展名，必要时撤销重命名 |
| 搜索结果太多 | 加入日期、课程或主题关键词 |
| 找到同名文件 | 查看完整路径和修改时间，不要只看名字 |
| 中文和空格导致命令行不方便 | 课程资料可使用清楚的英文或数字命名；不必为了命令行强行改掉所有中文 |

## 📝 本章总结

- 名称回答“是什么”，日期和版本回答“哪一份”。
- 搜索结果必须结合完整路径确认。
- 改名后要重新打开验证，不能只看文件还在不在。

## ✏️ 课后练习

把“最终版.pdf”“老师发的那个.pptx”“新建文件夹(3)”等练习名称改成可理解的名称，并写出你的命名模板。
