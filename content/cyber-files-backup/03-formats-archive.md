# 第 3 章：格式与压缩 — 文件后缀不是装饰

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 20 分钟 |
| 核心概念 | 格式、扩展名、压缩、解压、来源 |
| 核心比喻 | 包裹和包装 |
| 实践任务 | 安全解压并检查一份资料 |

PDF 适合阅读和交付，DOCX 适合继续编辑，CSV 适合表格数据，ZIP 是多个文件的包装。改后缀名不会真正转换格式，就像把纸箱贴成木箱并不会改变里面的东西。

!!! warning "先确认来源再解压"
    不打开来源不明的压缩包，不运行其中的脚本或程序；重要资料先扫描并解压到临时目录。

## ✅ 验证步骤

新建临时目录，解压一份可信资料，查看文件后缀和大小，再把其中内容移动到正式目录。确认没有覆盖已有文件。

分别说明 PDF、DOCX、CSV、ZIP 适合解决什么问题。
