# 第 3 章：格式和压缩 — 文件后缀不是装饰

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 55 分钟 |
| 核心概念 | PDF、DOCX、PNG、CSV、ZIP、压缩和来源 |
| 核心比喻 | 包裹和包装 |
| 实践任务 | 安全解压并打包一份练习资料 |

文件格式像不同形状的包装：PDF 适合阅读和交付，DOCX 适合继续编辑，PNG 适合图片，CSV 适合表格数据，ZIP 是把多个文件装进一个包。改后缀名不会真正转换格式。

## 3.1 先看后缀和属性

在文件管理器中打开“显示文件扩展名”，选择一个练习文件，右键打开属性或简介，记录文件类型、大小和修改时间。不要只根据图标判断格式，因为不同应用可能使用相似图标。

## 3.2 压缩和解压

压缩通常会生成 `.zip` 文件，解压会把里面的内容展开到一个文件夹。收到压缩包时先确认来源，再解压到“待检查”临时文件夹；不要直接覆盖课程目录中的同名文件。

1. 新建 `待检查` 文件夹。
2. 右键可信练习文件夹，选择“压缩”或“发送到 ZIP”。
3. 把 ZIP 文件复制到 `待检查`。
4. 打开 ZIP 之前，确认文件名和来源。
5. 选择“解压到新文件夹”，不要直接双击运行里面的程序。
6. 查看解压后的文件列表，再把需要的内容移动到正式目录。

!!! warning "先确认来源再解压"
    不打开来源不明的压缩包，不运行其中的脚本、安装程序或宏；重要资料先扫描并解压到临时目录。

## 3.3 选择合适的格式

如果要交付一份不希望别人随意改动的报告，通常使用 PDF；如果希望对方继续编辑，保留 DOCX；如果是大量表格数据，CSV 更容易被程序处理。发送文件前先问清楚对方要“阅读版”还是“可编辑版”。

## ✅ 验证步骤

把一个包含文本文件和图片的练习文件夹压缩成 ZIP；解压到一个新位置；逐个打开其中内容；比较解压前后的文件数量和名称。确认没有覆盖原始文件。

## ❌ 常见情况

| 现象 | 处理方法 |
|:---|:---|
| ZIP 打不开 | 先确认下载完整和来源可信，再使用系统解压功能 |
| 解压后出现很多重复文件 | 解压到新文件夹，不要直接覆盖原目录 |
| 改后缀后打不开 | 把后缀改回原样，使用真正的转换或导出功能 |
| 文件大小变大 | 某些图片和视频本来已经压缩，ZIP 不一定继续变小 |

## 📝 本章总结

- 文件格式决定内容如何被解释，后缀名只是提示。
- ZIP 是包装，不等于安全，也不等于备份。
- 解压到临时目录并确认来源，是初学者最重要的习惯之一。

## ✏️ 课后练习

分别说明 PDF、DOCX、PNG、CSV 和 ZIP 更适合解决什么问题；把自己的练习目录打包后解压，并写下文件数量是否一致。
