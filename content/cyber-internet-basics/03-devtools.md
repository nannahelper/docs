# 第 3 章：浏览器开发者工具 — 给网页装一扇观察窗

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 25 分钟 |
| 核心概念 | Elements、Console、Network |
| 核心比喻 | 透明的维修窗口 |
| 实践任务 | 找到网页的一张图片请求 |

Elements 看页面结构，Console 看脚本输出和错误，Network 看资源请求。它们是观察工具，不是随意修改他人网站的许可。

## ✅ 验证步骤

在公开网页中完成：用 Elements 找一个标题；用 Console 观察是否有错误；用 Network 筛选图片并记录一项资源的状态码。

!!! warning "尊重网站和隐私"
    不要把 Cookie、Authorization 请求头、个人信息或带登录状态的截图分享出去。

## ✏️ 课后练习

写下一个网页从打开到显示完成至少经历了哪些资源请求。
