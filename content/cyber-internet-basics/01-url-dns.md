# 第 1 章：连接网络和使用浏览器 — 先让网页出现在屏幕上

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 8 分钟 |
| 核心概念 | Wi-Fi、浏览器、地址栏、搜索框、标签页、下载 |
| 核心比喻 | 进入校园、打开图书馆和查看不同书桌 |
| 实践任务 | 连接可信网络并保存一份网页资料 |

手机能上网不代表你自然会用电脑上网。电脑需要选择网络，浏览器负责显示网页，地址栏和搜索框也不是一回事。

## 这一章只完成四件事

1. 连接一个你有权使用的网络。
2. 在浏览器地址栏打开一个公开网址。
3. 从新标签页回到原页面。
4. 保存书签并找到下载文件。

如果你在某一步卡住，先看“常见情况”并记录屏幕上的原话。不要跳过验证直接进入下一章。

## 先建立一张浏览器地图

浏览器是你和互联网之间的工作台。地址栏负责告诉它“去哪里”，标签页负责同时保留几条线索，历史记录帮助你回到曾经访问过的页面，下载列表则记录文件从哪里来。刚开始不必急着记快捷键，先把这些区域和它们承担的任务对应起来，之后遇到问题时才知道应该回到哪里找证据。

这一章的重点也不只是“成功打开网页”。你要观察网页是通过哪种网络连接打开的、地址栏显示的到底是什么、资料保存到了哪里。能回答这些问题，才算从被动浏览变成主动使用：你知道自己正在访问谁、拿到了什么，以及下一步怎样回到同一个位置。

## 1.1 连接一个可信 Wi-Fi

1. 找到屏幕边缘的网络图标并点击。
2. 确认 Wi-Fi 已打开，没有开启飞行模式。
3. 选择你有权限使用的校园或家庭网络。
4. 输入密码时确认大小写，不要把密码发到公开群聊。
5. 等待网络图标显示已连接。
6. 打开浏览器，访问一个你熟悉的公开网站。

如果网页打不开，先观察网络图标，再用手机确认其他设备是否也无法上网。不要立刻安装“网络修复软件”。

## 1.2 找到浏览器和地址栏

浏览器是 Chrome、Edge、Firefox 或 Safari 等应用。顶部通常有一条长输入框：输入完整网址时它会直接访问；输入普通问题时，它会交给搜索引擎。

在地址栏输入 `https://example.com`，按 `Enter`。观察页面加载、地址栏变化和返回按钮。不要把不认识的长链接直接粘贴到地址栏并登录。

## 1.3 标签页和窗口

点击加号创建新标签页；点击标签页标题切换页面；点击标签页上的关闭按钮关闭它。标签页像同一张书桌上的不同书，不要为了打开几个网页就创建几十个窗口。

## 1.4 阅读和保存一份网页资料

1. 打开一个老师或官方网站提供的公开资料页。
2. 先看地址栏域名，确认来源可信。
3. 使用浏览器的“添加书签”保存网页入口。
4. 如果允许下载，把 PDF 保存到一个你能记住的课程资料文件夹。
5. 打开下载文件，确认内容和来源一致。

## ✅ 验证步骤

完成“连接 Wi-Fi → 打开浏览器 → 在地址栏访问公开网址 → 新建标签页 → 返回原页面 → 保存书签 → 找到下载文件”。每一步写下屏幕上发生了什么。

## ❌ 常见情况

| 现象 | 先做什么 |
|:---|:---|
| 网络列表为空 | 检查 Wi-Fi 开关、距离和是否有权限 |
| 地址栏输入后跳到搜索 | 检查是否输入了完整网址和协议 |
| 打开了奇怪广告 | 关闭页面，不要点击“立即修复” |
| 下载文件找不到 | 打开浏览器下载列表查看保存位置 |

## ✏️ 课后练习

选择一个课程官网，保存它的书签并下载一份公开 PDF；重新启动浏览器后，从书签和文件夹两个入口分别找到它。
