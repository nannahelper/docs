# 第 1 章：网址与 DNS — 浏览器先要找到门

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 20 分钟 |
| 核心概念 | 协议、域名、路径、IP、DNS |
| 核心比喻 | 通讯录和门牌号 |
| 实践任务 | 拆解一个网址 |

网址通常包含协议、域名、端口、路径和查询参数。域名方便人记忆，DNS 负责把域名找到对应的网络地址。

```text
https://example.com:443/docs/start?lang=zh
协议       域名       端口 路径       参数
```

## ✅ 验证步骤

从一个公开网址中标出协议、域名、路径和参数；在浏览器地址栏中观察跳转前后的变化，不要把地址栏中的参数复制到公开场合。

## ✏️ 课后练习

解释“域名能打开但网页仍然报错”为什么可能不是 DNS 问题。
