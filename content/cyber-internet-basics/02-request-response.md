# 第 2 章：请求与响应 — 网页访问是一来一回的对话

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 25 分钟 |
| 核心概念 | GET、POST、状态码、请求头、响应体 |
| 核心比喻 | 前台填单与回执 |
| 实践任务 | 读懂一次 GET 请求 |

浏览器发送请求，服务器返回响应。`200` 通常表示成功，`3xx` 常表示跳转，`4xx` 常表示请求方需要修正，`5xx` 常表示服务端处理失败；状态码是线索，不是完整结论。

## ✅ 验证步骤

打开一个公开网页的开发者工具，在 Network 中刷新页面，找到一个文档或图片请求，记录方法、状态码、类型和大小。

## ✏️ 课后练习

找一个状态码为 `404` 的公开地址，解释它和“电脑没有联网”的区别。
