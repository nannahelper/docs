# 互联网与浏览器：从打开第一个网页开始

浏览器不是一个“输入网址就自动变魔法”的黑盒子。本教程从连接 Wi-Fi、认识地址栏和搜索框开始，带你观察网页请求、理解登录状态、下载资料并排查网页打不开的问题。

## 🎯 学习目标

- 能连接一个可信 Wi-Fi，并区分电脑没联网、网站故障和账号问题。
- 能拆解网址，理解域名、路径、参数和 HTTPS。
- 能在开发者工具中找到一次请求、状态码、资源类型和耗时。
- 能理解 Cookie、缓存、下载文件和登录状态的区别。
- 能在不泄露隐私的前提下记录网页故障并寻求帮助。

## 📋 前置要求

- 完成[电脑与操作系统](../cyber-computer-basics/index.md)第 1 章，或已经会打开浏览器和文件管理器。
- 准备一个公开网页和一个不含个人信息的练习页面。

## 🚀 开始前准备

第一次练习优先使用公开网页，不要在开发者工具里操作银行、校园账号或他人的登录页面。截图前检查地址栏、Cookie、邮箱和个人资料是否露出。

## ✅ 完成标准

你能打开一个公开网页，找到它的一次请求，记录状态码和资源类型，并解释“浏览器无法打开网页”至少可能有哪三种原因。
