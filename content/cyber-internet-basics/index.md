# 互联网与浏览器：网页是怎样打开的

把每天使用的网页拆成可理解的步骤：网址、DNS、HTTP、浏览器、Cookie、缓存和下载分别负责什么。

## 📖 关于本教程

| 项目 | 内容 |
|:---|:---|
| 适合人群 | 会上网但不了解网页背后过程的大学新生 |
| 预计时长 | 约 2 小时（包含观察练习） |
| 适用版本 | Chrome、Edge、Firefox、Safari 当前版本；开发者工具界面可能变化 |
| 维护状态 | 维护中 |
| 最后更新 | 2026-08-13 |
| 反馈入口 | [GitHub Issues](https://github.com/nannahelper/docs/issues) |

## 🎯 学习目标

- 能用地址、DNS、请求、响应解释一次网页访问。
- 能在开发者工具中找到状态码、响应时间和资源类型。
- 能区分网页缓存、Cookie、下载文件和账号登录状态。

## 📋 前置要求

- 会使用浏览器打开网页和下载文件。
- 不要求会编程。

## ✅ 完成标准

打开一个公开网页，找到它的一次请求、状态码、响应类型和耗时，并能解释这些数字大概意味着什么。
