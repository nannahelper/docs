## 📖 第一部分：单项选择题（20 题 × 2 分 = 40 分）

**1.**（单选）协议定义了两个或多个通信实体之间交换消息的（ ），以及消息发送/接收时采取的动作。

- A. 格式与次序
- B. 内容与长度
- C. 频率与速率
- D. 路径与跳数

??? answer "查看答案"
    **答案：A**

    协议三要素：**格式**（消息长什么样）、**次序**（谁先谁后）、**动作**（收到后做什么）。B、C、D 均非协议定义的要素。

**2.**（单选）关于分组交换与电路交换，下列说法错误的是（ ）。

- A. 电路交换在会话期间预留端到端资源，提供恒定速率
- B. 分组交换按需共享链路资源，允许排队等待
- C. 分组交换的端到端时延确定且可预测，优于电路交换
- D. 电路交换在静默期会浪费已预留的资源

??? answer "查看答案"
    **答案：C**

    分组交换的排队时延使端到端时延 **可变、不可预测**（这正是批评者的主要论点），而电路交换提供确定性的资源保证。A、B、D 均正确。

**3.**（单选）一条链路采用 TDM，每帧 8 个时隙，链路速率 1.6 Mbps，则每条电路获得的速率为（ ）。

- A. 100 kbps
- B. 200 kbps
- C. 400 kbps
- D. 1.6 Mbps

??? answer "查看答案"
    **答案：B**

    每条电路速率 = 链路速率 ÷ 每帧时隙数 = 1.6 Mbps ÷ 8 = **200 kbps**。电路交换下，每电路获得恒定速率，传输时间与链路条数无关。

**4.**（单选）传输时延（d_trans = L/R）的大小取决于（ ）。

- A. 分组长度与链路距离
- B. 链路距离与传播速度
- C. 分组长度与链路传输速率
- D. 传播速度与链路速率

??? answer "查看答案"
    **答案：C**

    d_trans = L/R 是「把分组全部推入链路的时间」，取决于 **分组长度 L 与链路速率 R**，与两节点间的距离毫无关系。与距离有关的传播时延 d_prop = d/s。

**5.**（单选）传播时延（d_prop = d/s）的大小取决于（ ）。

- A. 分组长度与链路速率
- B. 链路长度与传播速度
- C. 分组长度与传播速度
- D. 排队长度与链路速率

??? answer "查看答案"
    **答案：B**

    d_prop = d/s 是「比特在链路上跑完距离 d 的时间」，取决于 **链路长度 d 与传播速度 s**（约为 2×10⁸ m/s），与分组大小和链路速率无关。

**6.**（单选）当流量强度 La/R > 1 时，下列说法正确的是（ ）。

- A. 排队时延趋于 0
- B. 队列无限增长，分组到达速率超过链路发送能力
- C. 传输时延显著减小
- D. 传播时延变为 0

??? answer "查看答案"
    **答案：B**

    流量强度 La/R > 1 意味着比特平均到达速率超过链路发送速率，队列会 **无限增长**（现实中表现为缓存溢出、丢包）。流量工程的金科玉律是把流量强度设计为 ≤ 1。

**7.**（单选）服务器经速率 2 Mbps 的链路连路由器，路由器再经速率 1 Mbps 的链路连客户端，且核心网络无拥塞，则端到端吞吐量为（ ）。

- A. 0.5 Mbps
- B. 1 Mbps
- C. 2 Mbps
- D. 3 Mbps

??? answer "查看答案"
    **答案：B**

    吞吐量 = **瓶颈链路** 速率 = min(R_s, R_c) = min(2, 1) = **1 Mbps**。比特像流体流过管道，最细的管道（瓶颈链路）决定整体速率。

**8.**（单选）TCP/IP 五层协议栈中，自顶向下各层的数据单元依次为（ ）。

- A. 报文、报文段、数据报、帧、比特
- B. 报文段、报文、帧、数据报、比特
- C. 数据报、报文段、报文、帧、比特
- D. 报文、数据报、报文段、帧、比特

??? answer "查看答案"
    **答案：A**

    数据单元命名链：应用层 **报文（message）** → 传输层 **报文段（segment）** → 网络层 **数据报（datagram）** → 链路层 **帧（frame）** → 物理层 **比特（bit）**。这是 408 高频填空。

**9.**（单选）在 OSI 参考模型中，负责「断点续传」「会话同步」的层是（ ）。

- A. 表示层
- B. 会话层
- C. 传输层
- D. 应用层

??? answer "查看答案"
    **答案：B**

    会话层（Session）负责建立、管理与终止会话，提供 **断点续传** 与会话同步服务（2022#33、2019#33 等多次考查）。注意：加密/压缩/格式转换属于表示层。

**10.**（单选）数据压缩、加密与格式转换属于 OSI 参考模型中的（ ）。

- A. 会话层
- B. 表示层
- C. 传输层
- D. 网络层

??? answer "查看答案"
    **答案：B**

    表示层（Presentation）负责 **数据格式转换、加密/解密、压缩/解压**，让异构系统能理解对方的数据格式。记忆：OSI 七层「应表会传网数物」。

**11.**（单选）发送主机把应用层数据发送到链路的过程，正确的封装顺序是（ ）。

- A. 报文 → 报文段 → 数据报 → 帧
- B. 报文段 → 报文 → 帧 → 数据报
- C. 帧 → 数据报 → 报文段 → 报文
- D. 报文 → 数据报 → 报文段 → 帧

??? answer "查看答案"
    **答案：A**

    发送路径上逐层添加首部：应用层报文交给传输层加传输层首部成 **报文段**，网络层加 IP 首部成 **数据报**，链路层加帧首部成 **帧**，物理层把比特送上链路。

**12.**（单选）下列设备中，实现全部五层协议栈的是（ ）。

- A. 路由器
- B. 链路层交换机
- C. 主机（端系统）
- D. 集线器

??? answer "查看答案"
    **答案：C**

    因特网把复杂性放在网络边缘：**主机实现全部五层**；路由器实现第 1-3 层（可运行 IP，不识别链路层地址）；链路层交换机实现第 1-2 层（识别 MAC 地址，不识别 IP）。

**13.**（单选）HTTP 被称为「无状态」协议，其含义是（ ）。

- A. HTTP 不使用 TCP 连接
- B. 服务器不保存客户的任何状态信息，两次请求互不关联
- C. HTTP 不建立 HTTP 连接
- D. 服务器每次请求后都关闭连接

??? answer "查看答案"
    **答案：B**

    「无状态（stateless）」指 HTTP 服务器 **不保存客户的任何状态信息**——即使客户几秒内两次请求同一对象，服务器也照发不误。注意与「无连接」（交换报文前不先建立 HTTP 连接）区分。

**14.**（单选）浏览器请求的对象在服务器上不存在时，HTTP 响应状态码为（ ）。

- A. 200 OK
- B. 301 Moved Permanently
- C. 404 Not Found
- D. 505 HTTP Version Not Supported

??? answer "查看答案"
    **答案：C**

    **404 Not Found** 表示服务器上不存在所请求的文档（客户端错误）。200 表示成功；301 表示对象已永久迁移（配合 Location 首部）；505 表示服务器不支持请求的 HTTP 版本。

**15.**（单选）HTTP/1.0 非持久连接下，请求并接收一个对象（忽略传输时间）需要约（ ）。

- A. 1 个 RTT
- B. 2 个 RTT
- C. 3 个 RTT
- D. 0.5 个 RTT

??? answer "查看答案"
    **答案：B**

    非持久连接每个对象需 **2 个 RTT**：1 个 RTT 建立 TCP 连接（三次握手前两步），1 个 RTT 发送请求并接收响应（请求与第三次握手合并发出）。这是 HTTP 时间计算的基石。

**16.**（单选）HTTP 的 Cookie 机制主要用于（ ）。

- A. 提高传输速率
- B. 在无状态的 HTTP 之上识别用户、保持用户会话状态
- C. 压缩网页内容
- D. 加密用户数据

??? answer "查看答案"
    **答案：B**

    Cookie 的四大组件（Set-cookie 首部、Cookie 首部、用户端 Cookie 文件、站点后端数据库）在无状态 HTTP 之上 **创建了用户会话层**，用于购物车、个性化推荐、登录保持等。

**17.**（单选）SMTP 协议运行在（ ）之上，使用的是（ ）号端口，属于（ ）协议。

- A. TCP；25；推（push）
- B. UDP；53；拉（pull）
- C. TCP；80；拉（pull）
- D. UDP；110；推（push）

??? answer "查看答案"
    **答案：A**

    SMTP 用 **TCP（25 号端口）** 传输邮件，属于 **推协议（push）**——把邮件推给对端（接收方邮件服务器）。取邮件才是拉操作，用 POP3（110）/IMAP（143）/HTTP。

**18.**（单选）DNS 协议通常运行在（ ）之上，使用（ ）号端口。

- A. TCP；80
- B. UDP；53
- C. TCP；25
- D. UDP；67

??? answer "查看答案"
    **答案：B**

    DNS 运行在 **UDP 之上，使用 53 号端口**——避免三次握手的建连延迟，查询超时未收到回复可直接重发。注意：DHCP 用 UDP 端口 67/68。

**19.**（单选）DNS 资源记录（Name, Value, Type, TTL）中，Type = A 的记录表示（ ）。

- A. 域名到权威服务器主机名的映射
- B. 主机名到 IP 地址的映射
- C. 别名主机名到规范主机名的映射
- D. 域名到邮件服务器主机名的映射

??? answer "查看答案"
    **答案：B**

    **A 记录**：Name 是主机名，Value 是对应的 **IP 地址**（标准的主机名→IP 映射）。NS 记录指向权威 DNS 服务器；CNAME 记录给出规范主机名；MX 记录给出邮件服务器规范主机名。

**20.**（单选）下列关于应用层协议与传输层协议对应关系的叙述，错误的是（ ）。

- A. HTTP 运行在 TCP 之上
- B. SMTP 运行在 TCP 之上
- C. DNS 通常运行在 UDP 之上
- D. 因特网电话等实时应用必须使用 TCP

??? answer "查看答案"
    **答案：D**

    实时应用（因特网电话、视频会议）能容忍少量丢失、追求低时延与低开销，通常 **选择 UDP**（绕过 TCP 的拥塞控制与分组开销），并非必须用 TCP。判断口诀：需要「保证送到」的用 TCP，能容忍丢失的用 UDP。

## 📖 第二部分：简答题（2 题 × 5 分 = 10 分）

**21.**（简答，5 分）一个分组从源主机经多台路由器到达目的主机，沿途会经历哪四种时延？分别写出它们的含义与计算公式。

??? answer "查看答案"
    四种节点时延：

    1. **处理时延（d_proc）**：检查分组首部、确定转发方向、检错的时间，高速路由器中为微秒级或更小。
    2. **排队时延（d_queue）**：分组在输出队列中等待发送到链路的时间，取决于拥塞程度，**逐分组变化、最难刻画**。
    3. **传输时延（d_trans = L/R）**：把 L bit 分组以链路速率 R 全部推入链路的时间，与距离无关。
    4. **传播时延（d_prop = d/s）**：比特以传播速度 s 跑完链路长度 d 的时间，与分组大小无关。

    节点时延 d_nodal = d_proc + d_queue + d_trans + d_prop。

??? success "评分标准"

    - 四种时延名称各 1 分（共 4 分）
    - 公式正确（d_trans = L/R、d_prop = d/s）各 0.5 分（共 1 分，缺公式最多得 3 分）
    - 表述清晰、无概念混淆（如把传输/传播时延搞混）扣 1-2 分

**22.**（简答，5 分）DNS 的递归查询与迭代查询有什么区别？实际因特网中常用的查询组合方式是什么？

??? answer "查看答案"

    - **递归查询（recursive query）**：查询方请求 DNS 服务器 **代自己去取回** 映射——服务器承诺「我替你查到底，把结果给你」。
    - **迭代查询（iterative query）**：DNS 服务器回复「我不知道，但 **你应该去问** 某台服务器」，由查询方自己继续发起后续查询。

    **实际常用组合**：主机 → 本地 DNS 服务器的查询是 **递归** 的；本地 DNS 服务器 → 根/TLD/权威服务器的查询是 **迭代** 的。理论上任何查询都可是递归或迭代的，但全部递归会把负载压给根服务器，实际中几乎不用。

??? success "评分标准"

    - 递归查询定义正确（2 分）
    - 迭代查询定义正确（2 分）
    - 指出「主机→本地递归、本地→其余迭代」的典型组合（1 分）

## 📖 第三部分：真题实战（1 题 × 10 分 = 10 分）

**23.**（计算，10 分，**真题 2023#33 改编**）源主机 S 向目的主机 D 发送一个长度为 2400 B（= 2400 × 8 = 19200 bit）的分组，中间经过 2 台路由器 R1、R2（即共 3 条链路）。每条链路速率均为 R = 9.6 Mbps，每条链路的传播时延均为 5 ms；R1、R2 的平均排队时延分别为 1 ms、2 ms，各节点处理时延忽略不计。

（1）求每条链路的传输时延 d_trans；

（2）求该分组的端到端时延（含排队时延，存储转发方式）；

（3）若网络中其他流量骤增，使某条链路的流量强度 La/R 超过 1，会发生什么现象？链路层如何应对？

??? answer "查看答案"
    **（1）传输时延：**

    $$ d_{trans} = \frac{L}{R} = \frac{19200}{9.6 \times 10^6} = 2 \text{ ms} $$

    **（2）端到端时延。** 共 N = 3 条链路，每条链路经历（d_trans + d_prop），再加上两台路由器的排队时延：

    $$ d = 3 \times (d_{trans} + d_{prop}) + (1 + 2) = 3 \times (2 + 5) + 3 = 21 + 3 = 24 \text{ ms} $$

    即：传输 3 × 2 = 6 ms + 传播 3 × 5 = 15 ms + 排队 3 ms = **24 ms**。

    **（3）** 流量强度 La/R > 1 意味着比特平均到达速率超过链路发送速率，**队列无限增长、排队时延趋于无穷**（现实中是缓存溢出）。链路层应对：路由器输出缓存容量有限，分组到达时若缓存已满即被 **丢弃（丢包）**；被丢弃的分组由端到端机制（如 TCP）重传。

??? success "评分标准"

    - （1）传输时延公式与计算 2 ms（3 分）
    - （2）端到端时延公式（3 条链路累加）（4 分）
    - （2）正确计入两台路由器排队时延（2 分）
    - （3）流量强度超 1 的后果与丢包机制（1 分）

    本题改编自 2023 统考真题 33 题（分组交换网络中各种时延的计算）。
