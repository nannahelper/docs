# 账号安全与隐私：保护邮箱、代码和 API Key

账号是大学学习和数字生活的总钥匙。本教程不讲玄学防护，而是带你配置密码、双因素认证、恢复方式和密钥边界。

## 📖 关于本教程

| 项目 | 内容 |
|:---|:---|
| 适合人群 | 刚开始使用校园邮箱、GitHub、云盘和 AI API 的新生 |
| 预计时长 | 约 2 小时（包含配置练习） |
| 适用版本 | 主流浏览器、GitHub、常见密码管理器；设置项以当前版本为准 |
| 维护状态 | 维护中 |
| 最后更新 | 2026-08-13 |
| 反馈入口 | [GitHub Issues](https://github.com/nannahelper/docs/issues) |

## 🎯 学习目标

- 能为重要账号设置唯一密码和第二验证因素。
- 能识别钓鱼链接、危险授权和密钥泄露迹象。
- 能在泄露后撤销、轮换并检查影响范围。

## 📋 前置要求

- 拥有一个常用邮箱和一个可接收验证码的设备。
- 不要求学习密码学，但必须愿意保管恢复信息。
