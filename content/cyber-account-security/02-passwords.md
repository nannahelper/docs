# 第 2 章：密码和密码管理器 — 每扇门都用不同钥匙

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 15 分钟 |
| 核心概念 | 唯一密码、密码短语、主密码、管理器、恢复 |
| 核心比喻 | 每扇门不同钥匙 |
| 实践任务 | 为一个练习账号设置唯一密码并完成恢复检查 |

同一个密码复用会把一次泄露变成连锁失窃。密码管理器像带锁的钥匙柜，负责生成和填写不同密码；主密码和恢复方式必须单独保护。

## 2.1 好密码要解决什么问题

密码不应当是姓名、生日、手机号、学校简称或连续数字。更重要的是每个服务不同；一个服务泄露时，其他服务仍然不能直接被打开。不要为了“好记”把所有密码变成同一个模式。

## 2.2 选择密码管理方式

可以使用可信密码管理器，也可以先使用系统提供的密码保存功能。选择时查看官方来源、加密和恢复说明；不要把所有密码放进一个来路不明的浏览器插件。主密码不能和邮箱密码相同。

## 2.3 保存一个练习账号

1. 打开密码管理器的官方应用或官网。
2. 创建一个练习条目，不要第一次导入所有真实密码。
3. 使用随机生成功能创建密码。
4. 保存服务名称、登录网址和用户名；不要把验证码写进备注。
5. 退出密码管理器，再重新打开并查找这个条目。
6. 确认你知道主密码和恢复方式，但不要把它们写入云端普通笔记。

## 2.4 浏览器自动填充

自动填充很方便，但公共电脑和共享用户必须关闭或退出。输入密码前看地址栏域名，防止把密码填入钓鱼网站。

## ✅ 验证步骤

在你信任的密码管理器中为一个低风险练习账号生成唯一密码；退出并重新登录；确认自动填充只发生在正确域名，不要把密码复制到聊天框测试。

## ❌ 常见情况

| 现象 | 处理方法 |
|:---|:---|
| 忘记主密码 | 使用官方恢复流程，不向任何人发送主密码 |
| 自动填充在陌生网站出现 | 立即取消，检查域名和已保存条目 |
| 浏览器询问是否保存密码 | 私人设备可评估，公共设备选择不保存 |
| 一个密码用了很多年 | 先替换最重要账号，再逐步替换其他复用密码 |

## 📝 本章总结

- 唯一密码比“看起来复杂但到处复用”更重要。
- 主密码、恢复码和 API Key 不能混在普通聊天里。
- 自动填充前必须核对域名。

## ✏️ 课后练习

把一个低风险账号的重复密码替换成唯一密码，再检查是否启用了登录提醒；记录官方恢复入口，不记录密码本身。
