# 第 2 章：密码与密码管理器 — 每扇门都用不同钥匙

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 25 分钟 |
| 核心概念 | 唯一密码、密码短语、管理器、恢复 |
| 核心比喻 | 每扇门不同钥匙 |
| 实践任务 | 为一个账号设置唯一密码 |

同一个密码复用会把一次泄露变成连锁失窃。密码管理器像带锁的钥匙柜，负责生成和填写不同密码；主密码和恢复方式必须单独保护。

## ✅ 验证步骤

在你信任的密码管理器中生成一个随机密码，保存到一个测试账号，退出并重新登录，确认恢复流程可用。

!!! warning "不要把主密码交给任何人"
    支持人员不会通过聊天索要你的主密码、验证码或 API Key。

## ✏️ 课后练习

把一个重复使用的低风险密码替换成唯一密码，再检查是否启用了登录提醒。
