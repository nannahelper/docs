# 第 1 章：电脑的四层地图 — 先知道东西各自负责什么

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 20 分钟 |
| 核心概念 | 硬件、操作系统、应用、文件 |
| 核心比喻 | 学校的楼、校规、社团和资料室 |
| 实践任务 | 画出自己的电脑地图 |

把电脑想成大学校园：CPU、内存和硬盘是楼和房间；操作系统是校规和后勤；应用是正在办事的社团；文件是资料。看到“软件打不开”时，先问它属于哪一层。

## 1.1 四层分别做什么

| 层 | 负责什么 | 例子 |
|:---|:---|:---|
| 硬件 | 真实执行和保存 | CPU、内存、SSD |
| 操作系统 | 管理硬件、文件和权限 | Windows、macOS、Linux |
| 应用 | 完成某项任务 | 浏览器、编辑器、播放器 |
| 文件 | 被保存和交换的信息 | PDF、照片、代码、表格 |

## 1.2 小黄鸭复述

对着一只小黄鸭解释：“我打开浏览器时，操作系统把浏览器程序从硬盘交给内存，CPU 执行它，浏览器再通过网络拿到网页并显示出来。”解释不通的词，就是下一步要查的词。

## ✅ 验证步骤

打开系统信息，记录操作系统和处理器；打开文件管理器，找到一个 PDF；打开任务管理器或活动监视器，找到浏览器进程。把三件事分别归入上表。

## ✏️ 课后练习

选一个“软件打不开”的真实场景，写出它可能涉及的四层，不要先下结论。
