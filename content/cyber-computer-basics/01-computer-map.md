# 第 1 章：第一次坐到电脑前 — 先学会让电脑听懂你

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 50 分钟 |
| 核心概念 | 开机、登录、桌面、窗口、单击、双击、输入 |
| 核心比喻 | 认识一间新教室 |
| 实践任务 | 从开机进入课程页面并安全关机 |

本章不假设你“本来就会用电脑”。电脑不会读心，它只会按照你点击的位置、输入的文字和选择的按钮执行动作。每做一步都观察屏幕有没有变化，不要因为慢就觉得自己学不会。

## 1.1 认识你眼前的东西

| 名称 | 你可能看到的样子 | 先把它理解成 |
|:---|:---|:---|
| 屏幕 | 显示文字和图像的平面 | 黑板 |
| 鼠标指针 | 屏幕上的小箭头 | 你的手指位置 |
| 图标 | 小图片或小标志 | 某个入口的门牌 |
| 窗口 | 带边框的区域 | 一张摊开的纸 |
| 桌面 | 登录后看到的主要区域 | 工作台 |
| 任务栏或程序坞 | 屏幕边缘的一排图标 | 常用工具架 |

!!! info "单击、双击和右键"
    单击是按一下左键，用来选择；双击是连续快速按两下，常用于打开；右键会打开一个“还能做什么”的菜单。刚开始把指针停在目标中央，再慢慢操作。

## 1.2 第一次开机

1. 确认电脑接上电源。笔记本最好先接充电器，台式机要确认显示器和主机都已接通。
2. 按一下电源键。不要连续按很多次；如果屏幕没有立即亮，先等待一分钟。
3. 看到登录页面后，点击自己的账户名称，输入密码，再按 `Enter` 键。
4. 如果出现“正在更新”“请勿关闭电脑”，先等待，不要强制断电。
5. 进入桌面后，观察时间、网络和电量图标的位置。

### 你应该看到什么

你应该看到一个可以移动的鼠标指针、若干图标，以及底部或顶部的一排工具。看不到图标不代表电脑坏了，很多电脑会把图标放在开始菜单或应用程序文件夹中。

## 1.3 打开、移动和关闭窗口

1. 找到浏览器图标，单击一次；如果没有反应，等待两秒再判断。
2. 用鼠标按住窗口顶部的空白处拖动，把窗口移动到另一边。
3. 把指针移动到窗口四角，看到双向箭头后拖动，练习改变窗口大小。
4. 点击最小化按钮，观察窗口消失但程序没有关闭。
5. 从任务栏或程序坞再次点击浏览器，观察窗口回来。
6. 点击关闭按钮，等待窗口消失。

!!! warning "关闭窗口不等于删除文件"
    关闭窗口通常只是结束当前查看，不会删除电脑里的文件。删除文件通常需要把文件移到回收站或废纸篓，并进行后续确认。

## 1.4 输入、修改和复制文字

1. 打开记事本、TextEdit 或其他简单文本编辑器。
2. 点击白色编辑区域，看到闪烁的竖线后再开始输入。
3. 输入 `这是我的第一份电脑记录`。
4. 用方向键把光标移动到文字中间，按退格键删除一个字，再重新输入。
5. 用鼠标拖过一小段文字，使它变成高亮；按 `Ctrl+C` （Windows/Linux）或 `Command+C` （macOS）复制。
6. 点击下一行，再按 `Ctrl+V` 或 `Command+V` 粘贴。
7. 关闭窗口；出现保存提示时选择“取消”或“放弃”，因为本次练习不需要保存。

## 1.5 安全关机

先关闭正在使用的文件，等待保存完成，再打开系统菜单选择“关机”或“Shut Down”。不要直接拔电源，也不要长按电源键代替正常关机；只有电脑完全无响应时才把强制关机作为最后手段。

## ✅ 验证步骤

按顺序完成：单击选择一个图标；双击打开浏览器；移动、最小化并恢复窗口；输入、复制和粘贴一段文字；通过系统菜单关机。每项都做一次，做不到的项不要跳过。

## ❌ 常见情况

| 现象 | 先做什么 |
|:---|:---|
| 鼠标指针不动 | 检查鼠标线或电池，笔记本检查触摸板是否被关闭 |
| 双击总是失败 | 放慢速度，把指针停在图标正中央 |
| 窗口找不到 | 看任务栏或程序坞，可能只是被最小化 |
| 输入没有出现 | 先单击白色输入区域，确认看到闪烁竖线 |
| 电脑没有反应 | 等待几十秒，观察硬盘灯或风扇，不要立刻断电 |

## ✏️ 课后练习

从开机开始计时，完成“登录 → 打开浏览器 → 打开一个网页 → 最小化 → 恢复 → 关闭 → 安全关机”，把每个不确定动作写下来。
