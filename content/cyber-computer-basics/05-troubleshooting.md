# 第 5 章：网络、声音与外设 — 先检查公共设施

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 55 分钟 |
| 核心概念 | Wi-Fi、蓝牙、声音、显示器、打印机、设备状态 |
| 核心比喻 | 校园里的公共设施 |
| 实践任务 | 完成网络、声音和外设的基础检查 |

电脑连接的网络、耳机、显示器和打印机像校园公共设施。看到“网页打不开”时，不要立刻认定电脑坏了；先判断是电脑、连接、服务还是某个应用的问题。

## 5.1 连接 Wi-Fi

1. 找到屏幕边缘的网络图标，点击它。
2. 确认 Wi-Fi 已打开，选择你有权限使用的网络。
3. 输入密码时注意大小写，不要把密码发到公开群聊。
4. 等待图标显示已连接，再打开一个熟悉的网站。
5. 如果所有网站都打不开，查看是否开启飞行模式，或询问网络管理员。
6. 如果只有一个网站打不开，记录网址和错误提示，不要先重装网络驱动。

### 你应该看到什么

连接成功通常会显示网络名称或无线图标；浏览器打开熟悉的网站后应能看到页面。出现“已连接但无 Internet”说明电脑连上了路由设备，但不一定能访问互联网。

## 5.2 检查声音和耳机

先看系统音量是否为零或静音，再看输出设备是不是扬声器、蓝牙耳机或有线耳机。打开一个你信任的音频测试，逐项改变一个设置：取消静音、提高音量、重新插拔、选择正确输出设备。不要同时改很多项，否则无法知道是哪一步解决问题。

## 5.3 检查显示器、键盘和鼠标

显示器黑屏时先确认电源指示灯和连接线；外接显示器要选择正确输入源。键盘失灵时先检查是否误触锁定键；蓝牙键盘要确认电量和连接。鼠标失灵时先检查电池、连接线或触摸板开关。

## 5.4 检查打印机

先确认打印机有电、纸张和墨粉，再确认打印任务是否被暂停。打印前打开预览，确认页数和方向；不要连续点击几十次打印。发现重复任务后，打开打印队列并暂停或取消不需要的任务。

## ✅ 验证步骤

完成一张设备检查表：网络名称和连接状态、打开测试网页的结果、声音输出设备、键盘是否能输入、鼠标是否移动、打印机是否被系统识别。每项写“正常 / 异常 / 尚未检查”，不要凭感觉写“应该正常”。

## ❌ 常见情况

| 现象 | 先做什么 | 不要做什么 |
|:---|:---|:---|
| 所有网页都打不开 | 查网络图标和其他设备 | 立刻重装系统 |
| 只有一个网站打不开 | 记录地址和错误提示 | 连续刷新或点击可疑修复链接 |
| 没声音 | 查静音和输出设备 | 只把音量调到最大 |
| 打印多份 | 立刻暂停打印队列 | 反复点击打印按钮 |
| 外接屏幕黑屏 | 检查电源、线和输入源 | 拔插所有线缆并忘记原位置 |

## 📝 本章总结

- 先确认范围：一个应用、一个网站，还是整台电脑。
- 一次只改变一个条件，并记录变化。
- 看见“已连接”不等于网络一定能访问目标服务。

## ✏️ 课后练习

关闭 Wi-Fi 后重新打开，确认你知道从哪里恢复；拔下耳机并选择扬声器，确认声音输出变化；建立一个不会真正打印的测试文档，查看打印预览而不是直接打印。
