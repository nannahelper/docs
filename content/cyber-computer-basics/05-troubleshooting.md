# 第 5 章：电脑故障自救 — 把“坏了”变成可处理的问题

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 30 分钟 |
| 核心概念 | 现象、预期、复现、变化、回滚 |
| 核心比喻 | 校园报修单 |
| 实践任务 | 写出一份可交给同学或客服的故障报告 |

排错不是猜谜，而是做小实验：一次只改变一个条件，并记录结果。

## 5.1 五句故障描述

1. 我想完成什么？
2. 我实际做了什么？
3. 我期待看到什么？
4. 实际看到什么完整提示？
5. 什么时候开始、能否稳定复现？

## 5.2 安全排查顺序

先确认电源和网络，再确认应用和系统版本，接着重现最小步骤，最后才考虑重装。重装前必须备份个人文件，并记录软件配置和许可证信息。

!!! tip "小黄鸭原则"
    如果你无法把问题讲清楚，通常还没有收集够证据。把错误文字、截图、命令和时间写下来，再寻求帮助。

## ✅ 验证步骤

模拟“浏览器打不开某网页”，完成一份报修单，至少包含网址、时间、其他网页是否正常、浏览器版本和错误提示。

## ✏️ 结课任务

为自己的电脑建立一页“设备档案”：系统版本、常用应用、学习目录位置、备份位置和求助入口。不要记录密码或 API Key。
