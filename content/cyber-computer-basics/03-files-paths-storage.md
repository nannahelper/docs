# 第 3 章：文件、路径与存储 — 找到东西比下载东西重要

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 25 分钟 |
| 核心概念 | 文件名、扩展名、绝对路径、相对路径、磁盘空间 |
| 核心比喻 | 宿舍楼、房间和储物柜 |
| 实践任务 | 创建一套学习目录并定位文件 |

文件名是标签，路径是地址，扩展名是“它大概由什么工具打开”的提示。地址写得越清楚，越不依赖记忆。

## 3.1 建立学习目录

建议从一个稳定位置开始，例如 `Documents/University`，再按学期、课程和类型分层：

```text
University/
├── 2026-fall/
│   ├── courses/
│   ├── projects/
│   └── references/
└── inbox/
```

`inbox` 是暂存区，不是永久垃圾桶；每周把其中内容归档或删除。

## 3.2 观察文件地址

在文件管理器中复制一个文件的完整路径，注意路径中的空格、中文和扩展名。命令行中的相对路径则从“当前目录”开始，这就是为什么同一条命令换目录后结果可能不同。

## ✅ 验证步骤

创建 `University/2026-fall/inbox`，放入一个文本文件，分别从文件管理器和终端找到它，并说出它的绝对路径。

## ✏️ 课后练习

把三个下载文件改成包含“日期—课程—主题”的名称，不要使用 `最终版_final_真的最终版`。
