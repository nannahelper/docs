# 第 3 章：文件、路径与存储 — 先学会把资料放对地方

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 20 分钟 |
| 核心概念 | 文件、文件夹、路径、扩展名、磁盘空间 |
| 核心比喻 | 宿舍楼、房间和储物柜 |
| 实践任务 | 创建课程目录、保存并找到一份资料 |

文件管理可以先理解为整理宿舍：文件是物品，文件夹是抽屉，路径是地址，文件名是标签。下载一份资料不等于管理好它；重要的是下次还能找到、知道它是哪一版，并且不会误删其他资料。

## 3.1 创建自己的学习目录

1. 打开文件管理器：Windows 是“文件资源管理器”，macOS 是“访达”，Ubuntu 是“文件”。
2. 在左侧找到“文档”或 `Documents`，双击进入。
3. 在空白处右键，选择“新建文件夹”。
4. 输入 `大学学习`，按 `Enter`。
5. 双击进入它，创建 `2026-秋季学期`。
6. 在里面创建 `课程资料`、`作业提交`、`个人项目` 和 `待整理` 四个文件夹。

文件夹只是用来装文件和其他文件夹。它不是课程本身，也不会因为名字好看就自动备份。

## 3.2 创建、打开和保存一个文件

1. 进入 `课程资料` 文件夹。
2. 打开记事本、TextEdit 或其他简单文本编辑器。
3. 输入 `这是我的第一份课程记录`。
4. 选择“文件 → 另存为”，把位置选为刚才的 `课程资料`。
5. 文件名输入 `第一份课程记录.txt`，确认保存。
6. 关闭编辑器，再次进入文件夹并双击它。
7. 修改一句话并按保存，关闭后重新打开，确认修改仍然存在。

## 3.3 文件名和扩展名

扩展名是最后一个点后面的部分，例如 `.pdf`、`.docx`、`.png`、`.zip`。它提示系统应该用什么工具打开，但改扩展名不会改变文件格式。

推荐名称格式是 `日期_课程_主题_版本`，例如 `2026-09-01_math_notes_v01.pdf`。不要使用 `最终版_真的最终版` 这样的名字。

如果看不到扩展名，先在文件管理器的“查看”设置中打开“显示文件扩展名”。不要把 `记录.txt` 重命名成 `记录.pdf`，这不会产生真正的 PDF。

## 3.4 路径和搜索

绝对路径像完整快递地址，从磁盘或根目录开始；相对路径像“从宿舍门口往左走两层”，必须先知道当前在哪里。初学时优先使用文件管理器的完整路径。

右键刚才的文本文件，选择“复制路径”或“显示简介”，把路径粘贴到临时笔记中。然后回到文件管理器的搜索框，输入文件名的一部分，确认搜索结果仍然能找到它。

## 3.5 下载文件应该去哪

浏览器默认把文件放进“下载”文件夹。下载后立即做三件事：打开确认内容、改成有意义的名称、移动到课程目录。下载文件夹只适合做收件箱，不适合永久堆放。

下载一份公开 PDF 练习时：

1. 点击下载链接，等待下载完成。
2. 打开浏览器下载列表，确认文件名和来源。
3. 对 PDF 先确认来源可信，不要打开来源不明的程序文件。
4. 打开文件，确认内容是你需要的资料。
5. 把它移动到 `大学学习/2026-秋季学期/课程资料`。
6. 按日期、课程和主题重新命名。

## 3.6 查看磁盘空间

在系统设置中搜索“存储”或“磁盘空间”。记录总容量和剩余空间；不要看到大文件就直接删除，先确认它是否属于课程、系统或备份。回收站或废纸篓中的文件通常仍然占用空间。

## ✅ 验证步骤

从文件管理器完成：进入课程资料；打开刚才的文件；查看属性；返回上一级；再次进入并找到它。最后说出它在哪个磁盘、哪个文件夹、叫什么名字、是什么格式。

## ❌ 常见情况

| 现象 | 处理方法 |
|:---|:---|
| 文件找不到 | 先看“下载”文件夹，再按文件名搜索，最后检查回收站 |
| 双击后提示没有应用 | 先确认文件格式，再安装可信的对应应用 |
| 拖动后找不到 | 在目标文件夹搜索文件名，不要连续重复拖动 |
| 磁盘空间不足 | 查看大文件和回收站，不要删除系统目录 |

## 📝 本章总结

- 文件夹负责组织，文件负责保存内容。
- 路径回答“在哪里”，文件名回答“它是什么”。
- 下载目录是暂存区，课程目录才是长期住所。

## ✏️ 课后练习

创建两门课程的目录，分别放入一份文本记录和一份公开 PDF；关闭所有窗口后重新打开电脑，再用搜索和目录两种方式找到它们。
