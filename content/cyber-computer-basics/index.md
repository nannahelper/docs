# 电脑与操作系统：从第一次开机开始

给刚高中毕业、可能第一次独立管理电脑的你一张“电脑地图”。我们从开机、鼠标、键盘和窗口开始，逐步学会打开应用、整理文件、连接网络、查看设置和安全处理故障。

## 📖 关于本教程

| 项目 | 内容 |
|:---|:---|
| 适合人群 | 几乎没有独立使用电脑经验、准备开始大学学习的毕业生 |
| 预计时长 | 约 1.5–2 小时（按一遍阅读、跟做和验证估算） |
| 适用版本 | Windows 11、macOS 14+、Ubuntu 22.04+；界面可能略有差异 |
| 维护状态 | 维护中 |
| 最后更新 | 2026-08-13 |
| 反馈入口 | [GitHub Issues](https://github.com/nannahelper/docs/issues) |

## 🎯 学习目标

- 能完成开机、登录、打开和关闭窗口、连接网络等基本操作。
- 能理解硬件、操作系统、应用、文件和进程分别负责什么。
- 能创建学习目录、保存资料、查看文件信息和释放磁盘空间。
- 能检查应用权限、系统更新、声音、显示器和常见外设。
- 能把“电脑坏了”描述为别人可以复现和帮助排查的问题。

## 📋 前置要求

- 有一台可以正常开机的 Windows、macOS 或 Ubuntu 电脑。
- 不要求会编程，也不要求记住任何命令。
- 如果还不熟悉鼠标和键盘，请先预留时间练习点击、双击、右键、拖动和输入。

## 🚀 开始前准备

准备一张纸或一个空白文档，建立“我的电脑档案”。记录电脑品牌、系统版本、学习目录位置、备份位置和学校信息中心的联系方式，但不要记录密码、验证码或 API Key。

## ✅ 完成标准

你能独立完成“开机 → 登录 → 打开课程 PDF → 找到它的保存位置 → 关闭文件 → 安全关机”的完整流程，并能向别人说明每一步发生了什么。
