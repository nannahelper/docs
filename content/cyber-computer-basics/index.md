# 电脑与操作系统：从双击图标到理解计算机

给刚进入大学的你一张“电脑地图”：知道程序在哪里运行、文件放在哪里、系统为什么会卡，以及遇到问题时先查什么。

## 🎯 学习目标

- 能用“硬件—操作系统—应用—文件”四层解释一台电脑。
- 能找到文件、查看程序和进程，并分辨应用卡死与系统故障。
- 能用系统自带工具完成一次基础诊断，而不是盲目重装。

## 📋 前置要求

- 会使用鼠标、键盘和浏览器。
- 不要求会编程，也不要求购买额外软件。

## 🚀 快速开始

先不要安装优化软件。打开系统设置和任务管理器（或活动监视器），记录电脑型号、系统版本、内存和磁盘剩余空间；这些信息就是之后排错的“病历首页”。

## ✅ 完成标准

你能画出自己的电脑四层地图，并能回答：文件在哪里、谁在运行、哪个设置控制它、出问题时第一条证据是什么。
