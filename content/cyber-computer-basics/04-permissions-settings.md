# 第 4 章：窗口、设置与权限 — 电脑不是没有规矩的储物柜

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 20 分钟 |
| 核心概念 | 设置、账户、普通权限、管理员权限、更新、默认应用 |
| 核心比喻 | 门禁卡与校园规章 |
| 实践任务 | 找到设置、检查权限并安全安装一个工具 |

设置是电脑的控制面板；权限回答“谁可以对什么做什么”。普通账户像普通学生证，管理员账户像总钥匙。看到弹窗时先读清楚再决定，不要把“允许”当成每次安装的固定答案。

## 4.1 找到系统设置

Windows 点击开始菜单后搜索“设置”；macOS 打开“系统设置”；Ubuntu 打开“设置”。第一次不要急着修改，先浏览“系统、网络、账户、隐私和更新”这些区域。

记录以下信息：系统名称和版本、电脑名称、当前登录账户、是否接通电源、是否有待安装更新。不要记录密码。

## 4.2 普通账户和管理员账户

普通账户通常可以读写自己的资料；管理员账户可以安装软件、修改全局设置和影响其他用户。安装可信软件时系统可能弹出确认窗口，这是在询问是否允许改变电脑。

看到权限弹窗时：

1. 读完整句话，不只看“允许”两个字。
2. 确认是你刚才主动做的动作。
3. 确认应用名称和来源。
4. 不确定时点击“取消”，先查官方说明。

## 4.3 查看应用权限

检查一个常用应用是否能访问摄像头、麦克风、位置和文件。只打开任务需要的权限，不使用时可以关闭。

1. 在系统设置中搜索“隐私”或“隐私与安全性”。
2. 打开摄像头权限列表，找到一个你认识的应用。
3. 记下它当前是否允许访问。
4. 对不需要摄像头的应用关闭权限。
5. 打开视频通话应用时再按需开启，结束后复查。

## 4.4 更新和安装

更新可能修复漏洞、错误和兼容性问题，也可能改变界面或行为。更新前保存工作、接通电源、记录当前版本。应用只从官方网站、可信应用商店或学校提供的渠道安装。

安装前写下软件名称、下载来源和安装理由。安装时逐页阅读选项，取消不需要的开机启动、额外软件和浏览器修改。不要使用来路不明的“破解更新器”或“驱动修复器”。

## 4.5 默认应用和文件关联

默认应用是系统遇到某类文件时自动选择的工具。例如 PDF 可能默认由浏览器打开。默认应用改变不会改变文件内容；右键文件选择“打开方式”，可以先临时选择，再决定是否设为默认。

## ✅ 验证步骤

完成四件事：找到系统更新页面；查看一个应用的摄像头权限；确认 PDF 的默认打开应用；找到当前登录账户类型。每项写下“我在哪里看到的、现在是什么状态、我是否修改过”。

## ❌ 常见情况

| 现象 | 处理方法 |
|:---|:---|
| 找不到设置 | 使用开始菜单或系统搜索输入“设置” |
| 安装时要求管理员密码 | 先确认软件来源和用途，不要借用陌生人的账号 |
| 更新卡住 | 接通电源、等待一段时间，不要强制关机 |
| 摄像头不能用 | 查看物理遮挡、系统权限和应用内权限 |
| PDF 打开方式变了 | 右键文件选择“打开方式”，不要改文件后缀 |

## 📝 本章总结

- 权限是安全边界，不是安装流程中可以无脑点击的按钮。
- 更新和安装前先确认来源、用途和当前版本。
- 修改设置前记下原来的状态，这样出问题时可以恢复。

## ✏️ 课后练习

选择一个不需要摄像头的应用，关闭摄像头权限；再打开一个需要摄像头的测试页面，观察它为何被系统阻止，最后恢复你确认过的安全设置。
