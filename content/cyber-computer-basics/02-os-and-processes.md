# 第 2 章：电脑的四层地图 — 程序不等于正在运行

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 15 分钟 |
| 核心概念 | 硬件、操作系统、应用、文件、进程 |
| 核心比喻 | 校园、校规、社团、资料和正在办事的人 |
| 实践任务 | 观察一个应用从打开到关闭的变化 |

把电脑想成大学校园：CPU 像负责执行工作的工作人员，内存像当前使用的桌面，硬盘像长期存放资料的仓库；操作系统像校园后勤和校规；应用是浏览器、播放器等工具；文件是课件、照片、表格等资料。

## 2.1 硬件与软件

硬件是可以摸到或安装的部分：屏幕、键盘、鼠标、处理器、内存、硬盘、摄像头和网卡。软件是写在存储设备上的指令和资料。操作系统也是软件，它负责让应用能够使用屏幕、键盘、文件和网络。

!!! example "播放一段视频时发生了什么"
    视频文件保存在硬盘中；播放器请求操作系统读取它；数据进入内存并由处理器处理；画面显示到屏幕，声音送到扬声器。任何一层出问题，现象都可能只是“视频打不开”。

## 2.2 程序、窗口和进程

程序像放在仓库里的办事方案，只有打开后才会执行；进程像拿着方案开始办事的人。一个程序可以同时打开多个窗口，也可能在没有明显窗口时继续运行。

1. 打开浏览器，观察屏幕上出现窗口。
2. Windows 按 `Ctrl+Shift+Esc` 打开任务管理器；macOS 打开“活动监视器”；Ubuntu 打开“系统监视器”。
3. 在列表中搜索浏览器名称，不要因为看到陌生名字就全部结束。
4. 记下浏览器的 CPU 和内存数字，等待一分钟再观察它们是否变化。
5. 回到浏览器，打开一个新的标签页，再观察进程数量是否变化。
6. 正常关闭浏览器，再观察相关进程是否减少。

## 2.3 CPU、内存和磁盘空间

| 名称 | 用生活话理解 | 空间不足或占用过高时可能发生什么 |
|:---|:---|:---|
| CPU | 正在干活的人 | 操作响应变慢、风扇变响 |
| 内存 | 当前摊开的桌面 | 同时打开很多应用时变慢 |
| 磁盘 | 长期存放资料的仓库 | 无法保存文件、更新失败 |

不要把“内存占用率高”直接等于故障。浏览器打开很多页面时占用较多内存可能是正常的，要结合电脑变慢的时间和正在做的事情判断。

!!! warning "不要随意结束系统进程"
    不认识的进程先记录名称和位置，查找官方说明，不要因为名字陌生就结束。结束系统进程可能导致当前会话不稳定或未保存内容丢失。

## 2.4 应用无响应时怎么办

1. 看鼠标指针是否还能移动，等待 10–30 秒。
2. 如果其他窗口还能操作，先保存其他应用中的工作。
3. 记下应用名称、刚才进行的动作和屏幕上的完整提示。
4. 先尝试关闭当前窗口；只有无响应时才结束该应用。
5. 重新打开应用，检查文件是否自动恢复。
6. 如果问题重复出现，记录版本、文件大小和复现步骤。

## ✅ 验证步骤

打开浏览器、记事本和文件管理器，在任务管理器或系统监视器中找到它们；关闭其中一个，确认对应进程消失或数量减少；最后用自己的话说出 CPU、内存和磁盘分别是什么。

## 📝 本章总结

- 硬件负责真实执行和保存，软件提供指令和界面。
- 操作系统负责协调应用、文件、硬件和权限。
- 程序是存放在磁盘上的方案，进程是正在执行的实例。

## ✏️ 课后练习

写一张“应用无响应记录”：应用名称、刚才做了什么、等待多久、是否能复现、最后一条错误信息。不要只写“电脑坏了”。
