# 第 2 章：操作系统与程序 — 程序不等于正在运行

## 📋 本章概览

| 项目 | 内容 |
|:---|:---|
| 学习时长 | 25 分钟 |
| 核心概念 | 程序、进程、服务、窗口 |
| 核心比喻 | 校园管理者与正在办事的人 |
| 实践任务 | 找到并结束一个无响应应用 |

程序像存放在资料室里的办事方案；进程像已经拿着方案去办事的人。双击一个程序，系统才会创建进程，并为它分配内存和 CPU 时间。

## 2.1 观察正在运行的程序

打开任务管理器（Windows）或活动监视器（macOS），观察浏览器、文件管理器和系统进程。记录一个进程的名称、内存占用和 CPU 占用。

!!! warning "不要随意结束系统进程"
    不认识的进程先搜索其官方说明，不要因为名字陌生就结束；结束系统进程可能导致当前会话不稳定。

## 2.2 应用卡住时的顺序

1. 等待几秒，确认不是正在处理大文件。
2. 保存其他应用中的工作。
3. 记录应用名称和当前动作。
4. 只结束无响应的应用并重新打开。
5. 如果反复发生，再记录日志、版本和可复现步骤。

## ✅ 验证步骤

打开一个应用，确认它出现在进程列表；关闭应用，确认对应进程消失或数量减少。不要用“内存越低越好”判断系统健康。

## ✏️ 课后练习

写一张“应用无响应报修单”：应用、版本、正在做什么、等待多久、是否能复现、最后一条错误信息。
